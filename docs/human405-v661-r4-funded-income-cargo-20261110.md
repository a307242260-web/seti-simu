# 第四轮第 272 步：电收入后缺少可兑现的运输路线

从教师第 272 步的同一个存档出发，找到一条搜索没有生成的路线：**放蓝槽 1、研究蓝 4、触发阿米巴 1、放到电脑第 4 格插虫族 6 的电收入，随后把化石送到地球并领取虫族 3**。原图从这个收入端点最多 **220 V**；补上运输后 **223.5 V**，也高于原完整图的 **223 V**。这只是已验证的一条备选，不代表把它接入策略后的新根排序，也不代表整局分。

最好的路径在原存档用 **21 个正式输入**闭合（13 个准备、8 个运输与收尾），独立回放两次。白席主行动选蓝 4 的蓝槽 3；运输棋子先向内两格，再逆时针一格，实际花 3 电。结束时 **118 盘面分、183 已建立分**，剩 **6 钱、2 电、2 池数据、4 手牌、3 宣传**，电脑第 1 至 4 格已填。另两条原存档完整回放为 222.5 V，分别用了 20、19 个输入。完整输入来自未按状态等价合并的前缀边；比较原生资产时保留数据标记的放置顺序。原存档逐次恢复，真实 RNG 由原生内核推进；两个独立原生回放的完整终点、会话与 RNG 相同。

55 条收入计划都关联同一份运输。任务键仍是拾取时的探测器 5，实际载体是化石棋子 6；原生按化石 ID 对上，不是存档异常。53 条发生在主行动后，其中 39 条落在稳定状态且当前电量足够原生最短路线。其余包括直接遇到未知牌边界；未把那些盘面视为已证明能送达。旧完整图在收入以后只移动过普通探测器 7，没有移动这枚化石棋子，也没有选择完成这项运输。这里是缺少目的候选，和已有路线的排序差异是两回事。

39 个端点分别从同一份原生状态对照「直接结束」与「用 2 或 3 电运输、领奖再结束」；后者共 282 个实际输入，全部闭合并逐条复放。运输不增加盘面即时分，但当前已建立分均多 **4**，且均多 **2 钱、2 数据、1 宣传**。按原搜索遮蔽未知牌和科技奖励的口径，运输对各端点的旧图最佳续着 **12 胜、2 平、25 负**。最大损失来自花电后普通探测器原本能做的任务不再付得起；因此不能把运输奖励普遍加给收入，或者让固定运输覆盖原有后续。

同时试过延迟读取已经筹资的两次电脑放置之间的完整菜单。教师点 67 个中间节点中，搜索只读取 1 次完整菜单；独立原生复放覆盖相邻 134 次放置输入，状态、合法菜单和 RNG 一致。8 个冷根完整图一致，4 项定向 Node 通过。教师点五组中位数 **1,050.7→1,043.0 毫秒**，但逐对有三组反向；卫星点 **1,202.6→1,206.6 毫秒**。收益不稳定，而且延迟菜单依赖分支仍然打开，未纳入候选链。
