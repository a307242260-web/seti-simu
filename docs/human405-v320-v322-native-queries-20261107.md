# V320 至 V322 的探测器与扫描查询（2026-11-07）

## 已定位的瓶颈

V320 简化探测器内部计算：标准席位和三项橙色能力用有限索引查已经验证过的不可变几何；同一组已知收入候选共享扣除前的估值；只在有公开取牌奖励时建立公开牌列表。已揭示外星人时，当前分析后续规则会拒绝整个额外数据计划，探测器任务只改公开痕迹，不会让揭示状态倒退。没有省掉候选、游戏输入或可执行奖励。

V321 将已付电脑进度中固定的外星人踪迹奖励直接按分数和宣传上限报价。公开的第一与额外踪迹奖励仍来自正式规则；已揭示、会触发揭示或需要正式奖励的情况仍按原条件处理。320 组对照覆盖电脑进度顺序、重复、公开布局、宣传封顶和自定义权重。

V321 越过了“阿米巴前收入”，随后在“教师第三轮揭示阿米巴后”停下。该状态的 CPU 采样表明，预测探测器奖励时反复调用正式扫描目录，只要一个星球或星云坐标却计算了整张太阳系的可见轮盘。V322 复用正式星球与星云坐标查询，保留原始坐标归一化、菜单顺序、扫描目标和结算。该变动由 Browser 与 Simulation 共同使用；不改变规则、预算、状态等价或搜索剪枝。
