# 第三轮化石路线：用公开数据角标补足扫描付款

使用 `e68795e4a` 的生产规则和正式模拟器，复放[标准第 172 步的受控运输前缀](human405-prepass-funded-landing-20261113.md#第-172-步分支最晚一次放数据的真实代价)。它与正式局共享 23 输入开局，但第三轮早段固定了不同主行动，未证明生产 AI 会自行选出。其他三席照旧只 PASS 和处理必选；第三轮终点取本轮结算后、白席 PASS 选牌及下轮收入前。

原序在实际土星运输、分析和插电后保住 **112 盘面、6 科技、永久 7 钱／4 电／2 牌／0 宣传／0 数据／1 额外扫描、三手、两池、四电脑格、一蓝槽和在运化石 07**。和教师合法终点（105 分、六科技、7 钱／4 电、三手、三池、两蓝槽、化石 07）相比，仍少一池和一个已占蓝槽，科技组合、手牌和扇区进展不同。不能称为等价。末次扫描用三个地球目标与六个合法公共牌落点，**18 种都只产生两枚数据**；六种 B16 组合多 2 盘面分，但扇区位置不同，未合并原生状态。

从虫族 3 已经在手、即将支付登陆的同一原生存档，只交换两张未见普通牌。公开观察、合法菜单不变，已知虫族牌支付、化石拾取、分析和第 4 份永久电都可按相同动作执行。只换后面抽到的 B9，原路径保持；换掉 DLC14 则在实际第 89 个固定前缀输入失配：原路径需要 DLC14 的数据角标，才能用蓝 2 补 1 电并付末次扫描。失配后直接交回 AI，两组都能保住 7 钱／4 电和化石，但都是 119 分、两手、空池、空电脑和蓝槽。

只在真实揭示后改用公开付款：弃当时已知的 B9 得 1 宣传，以 3 宣传取已公开的 DLC15，再弃其角标得 1 池，填同一蓝 2，照原次序扫描。两组均恢复 **112 分、同六科技及收入、三手、两池、四电脑格、一蓝槽和化石 07**。该路径花掉原来的两点宣传，手里最后一张是 DLC13 或 B17 而非 B9，并改变市场。按同一末轮留牌，受控结果分别为 **221／259** 和 **204／236**（B111／B32），不能当作正式标准局成绩。此证据把「运输与 7 钱／4 电」和「晚段库存需要一枚可付款的数据角标」分开：已有公开备份能降低原牌序依赖，但目前只有固定前缀，未取得第三池，也未证明早期获取虫族 3 的整条路径对未知牌稳健。
