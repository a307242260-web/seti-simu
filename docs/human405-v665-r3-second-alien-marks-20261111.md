# 第三轮第二物种的三个取标时机

## 先扫南河三，再拿第二枚粉标

第 211 步，已知南河三有白席两枚信号，手里 B16，钱包 1 钱／2 电／5 宣传。先打 B16 花 1 钱，给南河三加一枚。用公司换牌只会把旧手牌放进市场，试过的三张公开换入牌均未让标准扫描出现南河三的公开牌目标。

改花 3 宣传购买一张已公开的牌后，市场实际补出 DLC16。再用两张手牌换 1 钱。下一回合才开始标准扫描，花 1 钱／2 电，地球扫描和已公开的 DLC16 各投一枚南河三，填满五格。早先织女一已拿过阿米巴粉标，这次仍可在已知阿米巴粉标和未公开物种之间选择。实验只在 DLC16 出现后提交它的扫描；购牌时不能用补牌身份保证这条路线。

- **第 190 步第一次分析。** 蓝标给第二物种后，少正式的阿米巴 7 数据角标，也少一枚即时数据。先紫 1、插阿米巴 1、再两牌换电，可以付清标准扫描。最好 **109／149、6 科技、7 钱／3 电、无探测器**。买 DLC25 后等实际展示 DLC17、公司换入并用其角标补电的对照，到 **105／145**，留下两张虫族牌。
