# 第四轮：让已经付得起的化石返程进入候选

V666 有电支付三格返程时，仍可能直接发射或换电：旧固定计划最多覆盖两格，且这些存档还有其他席位未 PASS，部分还留有普通探测器。V667 在十个已知返程存档中全部自主运回化石并领取任务。与各自同起点的 V666 对照，终局提高 **6–30 分**；最高 **227**，仍低于标准第三轮存档按同样保留牌接续的 **239／253**。这项改动解决的是第四轮兑现，不等于第三轮资产已经对齐。

## 怎么决定返程

第四轮主行动之前，根已看到虫族、在途化石、对应已知任务及地球位置，并且现有电足以付清最多三格、每格恰好一电的最短路径时，将返程作为一条固定准备计划。既有筹资方案优先沿用；新路径按坐标去重，不枚举不同走法、换资源或弃牌组合。每步核对原生移动和支付菜单，最后领取同一任务，再用实际剩余钱包比较主行动。没有借科技、额外卡牌触发、未知预留牌或临时任务的无歧义路径才启用；条件失效回到原策略。三格返程和领奖共七次正式输入，均在同一白席回合；其他席位没有被模拟成主动行动。

原版两处冷根因反复原生执行已经确定的蓝槽阿米巴选牌，达 272／286 次。只在第四轮阿米巴已公开、选中实例在当前公开区且是唯一固定选择时，复用原来的蓝槽结算。补位保持原信息边界。354 个真实选牌动作独立与原生比较完整规则状态、RNG、菜单和信息屏障，逐个一致。两个冷根降到 **196／204 次**，原本的策略首选和候选值保持。交换未翻开的普通、阿米巴、虫族牌堆顶部两张后，两个存档的白席观察、菜单、候选值、首选、原生输入数及 RNG 均不变。
