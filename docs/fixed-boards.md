# 固定盘面清单（seed ↔ 盘面 ↔ 初始公司）

本文记录 SETI 原型里所有被讨论/使用过的**确定性固定盘面**的关联关系。开始界面
「固定盘面」下拉可选的正式盘面、历史盘面、以及讨论中提过的候选 seed 都在这。
后续提到盘面时按这里的**指代名/seed** 对齐。

RNG 起点契约：任何 seed 的盘面都从 `hashSeed(seed)` 开始（`createInitialState`
显式 setState），Browser 与 Simulation 同一 seed 得到同一盘面（4 人局、weak_start）。

## 正式固定盘面（浏览器下拉可选）

### 1. `seti-107` —— 双发盘面（推荐主盘面）
- boardId：`seti-107-board-v1`
- 白色（人类）初始 2 选 1：**寰宇动力 / 异星实验室**
- 特点：**寰宇动力 = 双发**（被动火箭上限 +1 可造第二个探测器；主动能力两个探测器
  各走一步、必须选不同火箭）；异星实验室三色板块复用正式发射/扫描/科技行动
- 训练侧默认固定盘面（`FIXED_BOARD_CONFIG`）
- 盘面指纹：扇区 `{1:3, 2:2, 3:4, 4:1}`，轮步 `{w1:-5, w2:-20, w3:-12, w4:-9}`，
  公共牌 `[dlc_20.png, b_137.webp, b_83.webp]`

### 2. `seti-free-analyze-v1` —— 免电分析盘面
- boardId：`seti-free-analyze-board-v1`
- 白色（人类）初始 2 选 1：**异星实验室 / 深空探测**
- 特点：**深空探测 = 分析免电**（被动 `deepspace_free_analyze`，数据分析不消耗能量）；
  异星实验室三色板块复用发射/扫描/科技
- 盘面指纹：扇区 `{1:3, 2:1, 3:2, 4:4}`，轮步 `{w1:0, w2:-21, w3:-17, w4:-10}`，
  公共牌 `[b_2.webp, b_48.webp, dlc_21.png]`

| 公司 | 主动 1x 能力 | 关键被动 |
|---|---|---|
| 寰宇动力 | 两次各 1 移动力（不同火箭） | 火箭上限 +1（双发/第二探测器） |
| 深空探测 | 手牌与公共牌精确互换 | **数据分析免能量** |
| 异星实验室 | 三色板块复用发射/扫描/科技 | 蓝色发射 1 信用点 |
| 芬威克研究中心 | 1 宣传精选公共牌 + 弃牌角标 | 研究宣传费 5 |

| 任务中继站 | 2 宣传精选公共牌 + 收入角标 | 打牌获宣传/开局终局标记 |
| 哨兵探测网络 | 武装回合，打非外星牌结算弃牌角标 | 发射时扫描地球 |
| 层云核心 | 公共牌弃牌角标生成效果节点 | — |
| 赫利昂联合体 | 非蓝科技失效 + 手牌加收入 | 被动奖励槽 |
| 未来跨度研究所 | 精选公共牌 + 已扣牌目标分 | 预留牌相关 |
| 宇宙战略集团 | 精选公共牌 + 清空三色奖励槽 | 被动奖励槽 |

## 备注

- 浏览器：开始界面「固定盘面」下拉选择正式盘面，会锁定种子输入框为对应 seed；
  也可直接输入任意种子自定义盘面（4 人局、weak_start）。
- 训练侧：`randomizer/training/heuristic-policy.fixed-board.js` 的
  `FIXED_BOARD_CONFIG` 默认 = `seti-107`（双发盘面）；固定盘面报告/评测用
  `--seed` 覆盖。
