# 405 分教学：第二轮预投入、第三轮留牌和着陆时机

V445 的正式自主前三轮仍为 **15 → 48 → 116**，V189 的白席自主整局纪录仍为 **120**。本批从精确存档改变少数指定动作，重放规则状态、会话和 RNG。历史后缀中确实能做到 **132 分**，但那条路线是受控终局，不能登记为自主新纪录。

历史 V189 的第二轮尾部从同一原根比较三种路线：立即PASS、只登陆木星、登陆并用揭示的阿米巴牌发展，分别以 **34、46、50** 分结束第二轮。立即PASS后第三轮不用移动即可登陆同一木星位置，仍揭示同三张阿米巴牌，并能补同样的投入；代价是占第三轮两个主行动。第三轮完成同数主行动后，三者依次为 **50、50、52** 分，最后一条已发射探测器并取得橙4。比较到同一个泰坦尼亚目标时，立即PASS和只登陆的分支都只差1钱才能普通登陆；两条都能改用届时已持的DLC31，完成同一个+25分落点。三条在这一目的下均到77分，早发展路线余5钱，另外两条余4钱。故第二轮预投入的价值首先是释放第三轮主行动和留钱，并非唯一能到达该目标的路径。

泰坦尼亚方向的第一步属于明确的时机差异：原先发射后马上向外走，之后还需2点移动；推迟到转盘后再走需4点。对照三条线，推迟确实各多花2钱。原局第三轮普通登陆耗掉全部现钱，DLC31留到终局弃作1宣传。改在第三轮用DLC31登陆后，第四轮输入153—194逐个按原序合法重放，到最后科研前仍多5钱。单用这笔钱访问金星补宣传，终局仍120；环绕金星、完成B117第五次环绕或登陆，之后照原目标取得橙3，原生终局 **132**。这一对照只证明相对原局支付方式的机会；没证明今天的AI会自动选它。

### 候选与估值分开

历史第142步按同一钱包逐一重放14个可付款的持牌落点。在第一个结算状态，木卫一为62盘面、3钱4电、模型114.833；泰坦尼亚为77盘面、5钱0电、模型127.833。V450 将单一持牌名额交给粗估35的木卫一，原有行星路线退出，整个根从129降至123.833。该候选保留为失败证据。

V451 保留原来唯一的行星计划，最多增加一个正的确定分数卫星计划。正式付款下界、同一探测器和卫星身份、同一固定路径和原生共享前缀仍适用；保留手牌与打出手牌不是等价状态。历史根成功评价泰坦尼亚，**63次／173.592毫秒**且全部闭合，但它的127.833仍低于水星路线129。正式第179步仍选阿米巴0（176.5，**80次／299.294毫秒**）。V451 未准入。水星的129具体来自着陆之后选择阿米巴黄4，取得1分、公开阿米巴9及另一次匿名补牌。搜索止在隐藏牌边界：此时65盘面分、1钱、4池数据、两张牌；泰坦尼亚同回合结算至A标记，77盘面分、5钱、无池数据和手牌。两边计分、收入所需筹资和边界不同，不能将129和127.833直接解释为水星的整轮回报更高。下一步核查水星这4数据与公开阿米巴9的已知兑现，和泰坦尼亚省钱后的用途比较；不根据132给任意卫星加权。
