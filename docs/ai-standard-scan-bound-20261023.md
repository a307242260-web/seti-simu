# 普通扫描收益界与完成见证的展开顺序

2026-10-23：搜索v30、分析端口v31。默认工厂仍为256次输入、257节点、256前沿、600毫秒；
状态等价、可见信息、比较边界及每次一个真实输入均不改变。新证明不读取未知补牌内容。

## 普通扫描上界

`standardScanValueBound(node)`只识别正式地球扇区扫描后接一次公共牌扫描，止于公共补牌的信息边界。
接受稳定扫描前、已支付成本的首个目标选择及公共扫描选择三个阶段。
扫描队列来自Production `buildScanEffectQueue`，地球目标来自`getPlanetScanSource`及`listNebulaChoices`；
公共目标来自ScienceSession新增的纯查询`listPublicScanChoices`。后者将原有内部函数原样移出工厂，
正式Decision和分析端口调用同一函数，没有复制扫描编码、构造影子动作或改变执行规则。

限制如下，缺一项就返回null并继续原搜索：

- 公司仅图灵或异星实验室，四席、当前未PASS席位，无额外公司交互、临时奖励、外星人或运输流程。
- 无本席金标、保留牌任务/临时任务/终局公式/Pluto、可响应signalMarked的未消费触发器或匹配历史事件。
- 额外公共扫描数为0，公共区三张有效标准牌，补牌来源非空，正式剩余队列恰好是标准扫描及收尾。
- 没有已经待结算的扇区；逐对检查所有首扫/公共目标，替换一或两枚标记后仍有空位，不会完成扇区。
- 以原生标记顺序和`getNebulaSlotScoreReward`计算槽位分；两次命中同区时计算连续两个槽位。
  上界取所有目标对的最大分，不能把不同扫描目标当作等价。排除可能跨越金标阈值的状态。

默认V下，令q为剩余扫描次数、D为当前数据池数量、S为所有目标对最多获得的槽位分：

```text
valueDelta = S + 0.5 × min(q, 6−D) − remainingCreditsCost − remainingEnergyCost
```

稳定扫描前使用正式`getStandardScanCost`；已经付款的Decision不再扣成本。
公共扫描弃掉公共牌并补牌，不改变本席手牌或收入；本范围内没有其他得分或奖励。
上界须结合本席finalScore等于score、半整数安全数及冻结默认模型检查。
只有实际到达的全局见证V严格大于当前V加上界时，才省略扫描；相等继续展开，保留最短路径和actionId平分。

尚未执行的稳定扫描记录在`actionBounds`，根结果为value=null、not-executed，并引用上界及实际见证。
已付款Decision整体省略记`prunedByBound`。分别计入`scanActionPrunes`与`scanValuePrunes`，
未完成集合按实际已展开或已证明动作扣除，不制造边、叶值或模拟输入。纯付款根关闭全局扫描界。
watchdog发生在计算界期间时仍返回空动作和待处理义务；自定义V不使用默认模型证明。

## 与已有主行动后证明组合

原`postMainPlanSpec`已经证明被排除的交易、角标及移动继续路径不优于其保留的
数据角标、放数据、收入和结束回合路径。该证明已经逐项核对历史事件及不活动保留任务。
当它存在时，`postMainValueBound`允许以该保留集合的紧收益界覆盖原集合，记录
`continuationProof`和`continuationRetainedActionIds`。已知模型的钱电证明本身没有放宽。
其他公司、蓝科技、未知效果、临时任务、终局公式、金标等限制继续生效；就绪任务和可达历史触发仍拒绝。

## 展开顺序与全图结论

待展开表改为确定性的后进先出，先取得较深的实际完成见证，以便更早使用严格收益界。
这只改变处理顺序；所有正式后继、回边、精确身份及全局额度保留。完整后仍从边界逆向传播
最高V、最少输入和actionId代表。没有深度上限、逐根leaf cap、beam或启发式删支。

旧版本单独改顺序没有减少008的606次输入。本轮在新闭包上分别测量：

| 原型配置 | 完整008输入数 |
| --- | ---: |
| HEAD v29 | 577 |
| 只组合静止继续路径证明，原顺序 | 487 |
| 组合证明加扫描界，原顺序 | 328 |
| 组合证明加后进先出，不开扫描界 | 407 |
| 组合证明加扫描界及后进先出 | 248 |

这些原型均保持原首动作、V37.5和最短10步，源码分别归档；不要把顺序本身视作剪枝证明。
顺序对不同复杂窗口的收益不同，不能从此例外推全局速度。
