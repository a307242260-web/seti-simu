# 第四轮：用同一钱包计划移动和虫族 6 登陆

同一个教师 #272 起点，沿上次原生对照闭合到终局：**先橙 3 线 241 分；教师先扫描线 248 或 251 分**。教师线的两种结算分别用宣传和原手牌 DLC15 补橙 3。先橙 3 线第五个白席回合后只剩 PASS 和宣传买牌；试了直接 PASS，以及按两个顺序取并弃两张 #272 已知公开牌，都是 241。两种化石选择同值。这是既有固定后续的合法终局核验，没有重新运行整局，也没有穷举所有未知补牌和更早行动。

## 修复已经证实的候选缺失

此前虫族 6 只在探测器已到卫星时有估值。已有普通探测器距离土卫二三步，且钱电不够普通登陆时，AI 看不到原生可走的路线：留 **1 钱和虫族 6** 给登陆；剩余资源分配给移动角标、钱换电、一次两牌换电。两个证据根原估值分别为 231、230 V，探测器用途为 0；新报价分别补 9、10 V，均为 240 V。原生真正走完并结算的端点也都是 **168 盘面、236 已建立分、240 V**。三次进入已知位置的宣传共 3，用正式规则共用的公开判定计算，按宣传上限截断。

末轮仅本席可动时才启用。使用正式几何给出的同一个卫星目标，只支持最多四个一移动力的已知步、一个已知卡牌供应者和至多一次手牌换电。登陆卡不参与移动或换电；有未知保留牌、相关移动触发或资金不足时放弃报价。普通登陆和持牌登陆竞争同一个用途，未知化石、运输奖励及补牌身份不计入。完整观察、原生状态、轻量估值、公司换牌口径相同；遮蔽登陆卡或付款牌、扣掉留给登陆的钱时不再报价。

同一预算内把资金和移动作为一个固定候选；每步从正式合法菜单取描述，登陆后的扫描仍按当前回合规则处理，首次化石菜单仍是停止边界。两个根的原搜索最佳是 230 和 235 V，新增这条合法路线后均为 240 V。两个根实际由 AI 逐步决定并提交了 **31 步**，其中 **29 步**复用原计划证据，原生复放逐步精确一致。两处冷搜索分别 **79 输入／189 ms、81 输入／201 ms**。每个分支两种化石随后都原生闭合。
