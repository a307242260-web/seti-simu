# 第三轮：第二次研究改走阿米巴，任务和取牌收尾复用

从正式 V375 第179步的相同原生存档冷启动，隔离候选从旧候选的94分提高到 **101分、5项科技、6钱3电2牌1扫描永久收入**，轮末0钱1电、0宣传、0池数据，留阿米巴1，无探测器。仍先研究蓝1；第二次主行动不再弃阿米巴3和9研究蓝4，改打阿米巴0。之后自主执行阿米巴3移粉色痕迹领取红区奖励，再用深空探测把阿米巴1换成当时公开的 DLC25。31个输入逐一独立重放，规则状态、会话和 RNG 全部一致；这不是从23输入开局开始的正式实验。分数回到正式 V375 的101分，但少一项科技和探测器；教师105分、6科技、7钱4电和更多轮末投入仍未对齐。

第二次主行动的模型比较：研究蓝4为160，原阿米巴0只报159。按既有规则完成阿米巴3的确定区域效果后，真实局面仍是159；再按同一公司换牌策略取已公开的 DLC25，才到161.5。候选只在存在已知阿米巴0、免费区域牌和电脑分析能力时，用这条具体路径作估值：核查原生区域和已知奖励，换牌沿用既有固定策略，用同一价值账本；未公开普通牌、未来科技奖励和有盲抽的区域不进入该估值。只给涉及该目的的固定放数据尾部保留原生后继，第二次主行动的完整搜索由60增至68次。交换两张未知普通牌与未来科技奖励时，原第179步和第二次主行动的根排名与报价不变。原第179步的阿米巴0虽然因区域作用从153.5涨至156.5，仍低于蓝1研究的158.5；没有用旧痕迹重复计分翻转它。

另从强制早打阿米巴0和阿米巴3黄色区域的同一个检查点，分别执行「分析、再研究」和「研究、再分析」，蓝1与紫1各两条。若两步之间不另做准备，**两种顺序完成后完整原生存档和 RNG 相同**：蓝1都为88分、3池数据、3宣传，紫1都为85分、5池数据、4宣传。两组均保留相同四张牌。早分析的用途应来自中间能提前填电脑或插收入；不能靠给顺序加固定分。该教学方向分析后的实际冷根仍要551次／约800ms，主要是收入113次、蓝槽取牌97次和电脑前三格88次；另两处前置冷根只要44和59次，但都仍选研究。

性能对照把两类固定尾部按同一规则报价：
- 宣传已满、只有一项已就绪的纯宣传任务时，分别核对「蓝槽取牌后立即领任务」和「蓝槽取牌后结束并延期」。立即领会消耗任务、增加完成次数但没有可入账宣传；延期继续保留可兑现的宣传。两种结果分别估值，必要时回退原生。9组原生对照证明，只要确实既领任务又取牌，交换顺序后的存档完全相同；先取牌再延期仍有独立价值。8条满足快捷报价条件的路径两臂均独立重放。
- 原生策略先插一张已知钱电收入、后只剩下结束或取已知蓝槽牌时，沿用同一个蓝槽报价，同时比较结束与取牌两种尾部。若还有其他数据用途、待处理任务、移动或新的取牌目的，则保留原生。8条收入先行路径的两臂均独立重放，选牌、估值、准备负担、兑现和长度与原图一致。

同一个科研前对照根从 **416降到368次**，各三次交替冷测中位耗时从656降到611毫秒；另一个科研根90降到82次。对没有蓝槽快捷证明的原始搜索图，共29条尾部逐条核验，其中16条分别重放了两个结尾；三根的首选及各根估值一致，交换补牌顺序仍一致。五项定向 Node 测试和 Chrome 通过，先前的 ready-Amiba 输入审计断言仍失败。前两轮各抽6个已存根，完整搜索图、动作、估值和次数与上版一致，未以抽样代替准入。

两处慢根都未通过256次／600毫秒门槛，候选保留为补丁与证据。没有新跑正式自主前三轮，实验中心的 V375 和 V41 基线保持。下一步从教学方向分析后551次的根缩短收入与电脑固定准备，并在已证明两步等价的共同起点，比较不同准备插在两步之间的真实收益。
