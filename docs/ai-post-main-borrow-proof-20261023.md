# 图灵主行动后的无效借用归约

搜索v26在`postMainPruning`下增加`seti-post-main-turing-shorter-continuation-v1`。
只减少当前窗口内不能改善任何后继的借用；保留最大默认V、最短正式输入和首步actionId平分规则。
本证明不把临时科技计作永久科技，也不声明原始复杂主行动已经完成探索。

## 适用范围与状态关系

可信端口`postMainBorrowSpec`要求稳定且没有Session，本席主行动已经完成，仍可正式启用图灵借用。
沿用`knownCardMoneyOrder`的已知模型闭包、标准交易、四席、非开局、其他owner轮内交接等前提；
此外排除已有借用、就绪外星揭示、化石运输和本席特殊探测器。
本席全部保留牌的普通/临时任务及触发器，其后续只能获得资源、数据、盲抽、精选或免费移动。
Pluto附加能力、可发射/扫描/研究/环绕等后续效果，以及未知模型均不适用。
合法行动族限定为结束、数据、交易、角标、移动、公司和完成任务。

对比同一稳定状态S的两条路径：直接保留S，或正式启用公司再借用某块无作用科技。
后者仅改变本轮公司标记和临时借用字段；不消耗/获得资源，不触发额外奖励，不改变永久拥有科技、RNG或实体。
S可以执行借用路径的全部其他继续步骤，并拥有尚未使用公司能力的额外选择。
这是单向模拟关系，不是精确状态相等；原有向前身份完整保留公司字段。

## 科技用途闭包

图灵只能从正式`techBoardState.isSlotAvailable`的橙/紫槽借用，不能借蓝色科技。

| 科技 | 当前窗口中仍可能起作用的用途 |
| --- | --- |
| orange1 | 发射数量上限；主行动完成且保留区不能再发射，故无作用 |
| orange2 | 离开小行星的移动点数及进入小行星的宣传；继续保留 |
| orange3 | 登陆能量折扣；本闭包不能再登陆，故无作用 |
| orange4 | 卫星环绕权限；本闭包不能再环绕，故无作用 |
| purple1～4 | 扫描及其追加流程；本闭包不能再扫描，故无作用 |

若orange2已永久拥有且有效，借用它也无作用；已失效的永久orange2仍须保留借用选项。
现有任务可以保留访问水星抽牌、访问金星宣传、访问小行星获得数据等真实收益，不能据此删除移动。
永久科技数、科技计分和默认V读取永久归属；临时借用不会额外加一块永久科技。

删去无作用的启用和借用后，原路径的V及其他后继不变，正式输入严格减少2次。
因此这条路径在V相同时无法胜过更短原路径，尚未进入actionId平分环节；不需要改变平分政策。
同owner下一回合、跨轮或终局不在本证明起点的交接范围，未知或越界状态继续普通搜索。

## 执行、覆盖和复用

没有任何仍有作用的可借科技时，从S的合法集中省略整项industry；保留其余全部行动。
如果同时已有另一局部归约，当前实现保守地不合成这一整项省略。
orange2仍有作用时，用`expandPostMainBorrow`执行正式启用和正式选择，两次输入均计入全局额度。
宏读取并核对实际全部借用选项，与证明中的公开供应列表不符或没有回到稳定边界即显式失败。
不执行其余无作用借用，不伪造节点、值或虚拟正式边。

借用宏内部的待选节点不成为新的图节点；其原始两步actionId保存在边的steps中，边成本为2。
真实根已处于借用Decision时无法撤销启用，完全不适用此证明，仍比较全部真实选项。
普通前缀证书不会跨越宏内部；真实点击到待选后重新计算，不把原窗口外的“跳过启用”当作合法选择。

完成标记要求保留图全部闭合，省略科技绑定原起点继续搜索以及真实边界见证。
存在全局归约时根候选值只标为实际到达的下界；预算未闭合仍返回空动作和空证书。
纯付款出口集合及其复用不变；原全局256输入、257节点、256前沿、600ms配置不变。
新归约限默认V和至多4096输入的诊断范围，算法版本使旧证书失效。
