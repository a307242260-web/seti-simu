# 第四轮：复用电脑收入报价的放置前缀

卫星压力点在同一批九组冷测中，耗时中位数从 **1,613 → 1,586 毫秒**（候选范围 1,568–1,630），仍是 254 次原生输入。教师 #272 从 **1,065 → 1,059 毫秒**，仍为 156 次，首选仍是立即登陆海卫一。这项优化省下的是计算准备，未改变策略，未通过 600 毫秒门槛。

同一个玩家快照给多张收入牌报价时，先在原生电脑放置规则下放数据，结算确定槽位奖励，再分别使用每张候选牌。现在只对完整不可变的同一个玩家快照共享前半段；收入、手牌、估值和数据收入的新标记各自计算。公开预览继续返回独立的可变数据账本，数据收入也继续使用独立账本和实体编号。没有减少候选、增加搜索分支或改变预算。卫星压力点 2,795 次报价中有 2,424 次再次遇到同一玩家快照。另试过按玩家扩展状态判重缓存及缓存选牌信息，未见稳定提速，未合入。

本批脚本与正式 Simulation 宿主一样，转发 `cheap` 和 `valueOnly` 观察选项。旧版单点复现脚本没有转发，额外计算了其他席位的分数，旧批耗时不用于这里的净提速比较。两版各开新进程并轮换顺序；教师与卫星点各九组，正式第四轮入口、橙 1 发射后及两个第三轮点各一组。六处完整搜索图、估值、排序、原生输入及源存档（含 RNG）均一致。

独立逐项比较 **3,862** 份旧／新报价端点，含同玩家多张收入牌、资金不足和数据收入；端点内容全同。四项 Node、V 输入审计和两项 Chrome 检查通过。正式第四轮入口在这批单测是 634 毫秒，橙 1 发射后 422.7 毫秒；卫星和教师 #272 也仍超时。没有启动新整局，实验中心成绩保持。卫星仍有 1,596 个图节点和 618 次估值，下一步重点是这些状态中重复生成的扫描／收尾计划，以及 #272 两条路线对同一钱包的跨回合使用。
