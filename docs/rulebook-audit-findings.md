# 规则核对结论（当前状态）

本文记录说明书核对后**当前仍然有效的规则事实**（用户/owner 确认的设计决定与开放项）。历史问题与修复过程已归档完毕，不再保留在文档中；当前机制现状以 `docs/mechanics-reference.md` 为准。

## 已确认的规则实现（用户/owner 确认）

- **外星人槽位 2 首痕迹奖励不对称**：规则书 P11 文本为「放标记到发现位置获得 1 推广 + 5 分」，但实体版图两槽位不对称（槽 1=5 分+1 宣传、槽 2=3 分+1 宣传、溢出 3 分）——**实现与实体一致，非 bug**。
- **核心机制确认无误**：发射（2 信用/上限 1）、移动（1 能量=1 移动力/离开小行星+1/进入行星彗星+1 推广）、绕行（1 信用+1 能量/首个 +3 分）、登陆（3 能量/有卫星 2/橙3 -1/首个得数据/卫星需橙4）、扫描（1 信用+2 能量/至少 2 信号/延迟补牌）、分析（1 能量/第 6 位/清空/蓝色痕迹）、研究（6 推广/首个拿取者 +2 分）、收入（插入即得/第 2 轮起）、资源转换（2 同种换 1）、买卡（3 宣传）、数据池 6/推广 10、扩展模式（起始推广 0/4 轮/内部 2-4 轮收入）、终局 8 板块公式（a1/a2/b1/b2/c1/c2/d1/d2 ↔ 规则书 8 面）、8 个扇区赢家奖励表、8 外星人配件数量与通用机制、11 家公司目录与能力、扫描码→颜色→扇区映射。
- **L1 促销牌混入**（b_139 冥王星自定义保留牌、b_140 促销牌「Gateway to Mars」）：**用户确认保持现状**（house rule，接受）。
- **L7 紫2/紫3 编号与实体一致**（紫2=水星、紫3=弃手牌），非 bug。
- **L10 快速起始牌收入**：快速起始牌没有收入角标，而是特定牌卡面直接说明「可作为什么收入插入」；仓库初始牌模型中带 `income` 效果的牌（如 7 号「1数据收入」、9 号「1盲抽收入」）对应这类牌，收入已在初始结算时写入 `player.income`（`initial-cards.js applyIncome`）。
- **L11 收入逐图标结算**：初始收入按 `incomeIncreaseCount` 生成逐图标队列（`paymentChoices` 实时读手牌），新获得的卡牌可立即用于下一图标；轮初收入聚合发放符合规则书 P19。
- **L12 金色板块 3 槽位**：3 档位（1/2/3），3 号位可无限放多个标记——**用户确认实现正确**。
- **M4 钻探者=九折**（用户核对说明书第 3 页）：基础 5 种外星生物为硫铵虫（10 张=虫）、钻探者（15 张=九折）、异常点、半人马族、奥陌陌，卡牌数量与仓库物种吻合。说明书 P20/P28 只豁免钻探者（九折）：九折牌不进手牌，豁免自然成立；虫（硫铵虫）牌无豁免，按普通手牌计入手牌上限、可作弃牌/资源转换费用。

## 开放 / 观察项

- **L4 冗余（额外）痕迹无限堆叠** vs 规则书「固定冗余位置」设计：规则书未明示上限，观察项。
- **L5 基础 5 轮模式未实现**（实现 = 扩展 4 轮模式，与扩展规则书一致）：若产品声明支持基础模式则为范围缺陷。
- **L6 紫4「移动」免费** vs 规则文本直译 1 能量：仓库文档与社区解读（Seti Fan Hub）支持免费移动，需官方确认。
- **L3 火星首登陆「任选两个数据位之一」简化为固定 2/1 数据**：功能等价（2>1，无理性玩家会先选 1 数据位）。

- **公司被动 UI 显示缺口（观察项）**：`industry.shouldShowStrategyPassiveMarkers`、`shouldShowHeliosPassiveMarkers`、`shouldShowAlienLabPanels`、`shouldShowFutureSpanPanel`、`isSentinelCornerArmed` 目前无外部调用，浏览器只渲染公司牌 token 图与 1x 主动能力按钮；异星实验室三色面板、未来跨度标记、宇宙战略+赫利昂奖励槽、哨兵角标武装状态在 web UI 上未呈现——机制层已接线（见 `docs/mechanics-reference.md`），仅 UI 展示缺失，待补。
