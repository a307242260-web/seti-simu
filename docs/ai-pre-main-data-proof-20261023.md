# 主行动前已有四数据时的严格准备剪枝

证明：`seti-before-main-funded-data-strict-plan-v1`，搜索v25在既有`openingPruning`开关下使用。
只用于冻结默认`seti-linear-state-value-v1`；不是把数据视为可任意删除的状态等价。
所有实体、资源、任务、队列和RNG仍进入原精确身份；付款的全部实体集合不变。

## 范围和资源下界

`preMainDataPlanSpec`在可信分析端口读取本席稳定主行动前节点，未知状态返回null。
它复用`knownCardMoneyOrder`的模型、资源、合法族及下一owner校验；该钱电范围校验本身不证明数据可替换。
另外要求：

- 公司只能为已核对的图灵系统或异星实验室。图灵只借橙/紫科技，不能在主行动前取得蓝科技或数据。
- 本席至多5张手牌，无蓝科技、停放牌、非标准/化石探测器或运输任务；无当前事件及待揭示物种。
- 手牌角标代码仅0–2、实际倍率1；数据角标只给1数据，收入仅单项1钱、1电或1手牌。
- 池数量与availableData一致，计算机是连续前缀，没有蓝色附加位数据。
  2格严格只给1宣传，4格严格只给收入，其他计算机格没有奖励，分析仍需6格。
- 本席全部手牌/保留牌模型拒绝dataTotal、resourceEquals和剩余数据计分。
  这包括以后主行动才打出的牌，避免改变数据、手牌或宣传后阻断条件与计分。
- 保留牌任务/触发奖励只允许gain_resources、draw_cards、pick_card、card_move；不得观察cardCorner。
  所以主行动前没有额外数据、蓝科技、回手新牌或另开的科学流程；取新牌在信息边界停止。
  标准移动只给到达宣传，特殊探测器及运输已排除。

记`stock=已放计算机数据+池数据`。要求`stock>=4`，且`stock+全部剩余数据角标数<6`。
后者是所有主行动前数据来源的乐观上界；主行动前分析因而不可达，不能把“当前analyze不合法”冒充可达性证明。
主行动新得到的数据不能用于第二次主行动分析。研究/取牌的新信息仍按原屏障停止，不继续使用未知奖励。

## 路径模拟和PASS例外

现金收入的数据角标把1手牌换成1池数据，当前净损失0.5V。保留这张牌、少1数据时，
原来其他行动、付款和条件路径仍可执行；已有四数据足够取得前四格的所有收益，后两格无奖励且不能解锁分析。
不影响收益的多余放置可不执行。现金/手牌/数据的差异不能触发已排除的条件或数据计分。
若原4格空手而跳过收入，插入保留的现金牌：真实多一次输入，增加1钱/电和非负未来收入，
可继续原后继，不产生盲抽屏障；相对少掉的1数据至少严格多0.5V。

PASS不能仅按“手牌更多”处理。原先用角标消耗一牌后至多4牌，保留它可能新增一次强制弃牌。
因此五手牌只在第1/2轮、4格收入尚未领取时接受：到原PASS位置后，用现有四数据填到4格，
插入保留的现金牌，再执行PASS。与原路径相比至多少5个池数据，最多损失2.5V；
多1现金及至少2次未来现金收入，至少增加3V，另有非负宣传收益。手牌与原路径重新相同且至多4张，
所以至少严格多0.5V，不把新增收入输入当作免费步骤。

第3轮可能同值但替代路径更长，第4轮可能更差。五手牌在后两轮或4格已占用时返回null。
本席原有至多4手牌时，保留目标也不超过PASS上限，不需要五手牌替代；仍只省略现金数据角标。
4格已占用且不受五手牌例外影响时，数据角标和普通放数据均不能取得新收益，允许省略。
盲抽数据角标在4格之前继续保留，不能用提前遇到信息屏障替代完整原路径。

这些结论删除的是严格劣势路径，因此最大V、最大值的最短输入及首步actionId平分顺序保持。
当前数据已能凑满6格、存在额外数据来源、蓝奖励、数据/手牌/宣传条件或相关计分时均继续原搜索。
增加模型特征、效果原语、公司能力或数据奖励时必须重审。

## 合成、预算及完成证据

端口按节点WeakMap缓存前提，close释放；策略仅收到证明、原合法actionId及公开数量下界。
`preMainDataProofNodes/preMainDataExcludedActions`只统计实际新增的省略项。
没有旧局部计划时使用`kind=pre-main-data`；已有开局严格计划时取保留集交集、排除集并集，
保留两份完整`componentPlans`，证明ID为`seti-composed-before-main-strict-plans-v1`。
没有把旧计划引用的某个代表值复制成省略根的执行结果。

仍用全局256输入、257节点、256前沿和600ms配置；诊断至多4096/4097/4096/15秒。
没有深度、逐根叶数或beam截断。只有保留图闭合才返回动作；省略根仍为null值/target和not-executed，
绑定真实保留见证，未闭合时见证与动作均为null。纯付款的每个实体集合继续精确求值。
版本v25使旧前缀证据失效，复用仍检查完整依赖。
