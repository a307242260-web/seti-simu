# 第四轮扫描痕迹：已知奖励局部比较，保留外星牌

以[电脑收入收尾](human405-v661-r4-income-prefix-20261109.md)的两个教师冷根为对照。每根有 6 个扫描状态进入同一个 7 项粉色痕迹菜单，共提交 42 次。分支包含不同扫描分、化石已领或未领；不能直接把这些状态视作同一个。六个选项可立即结算，另一个会打开阿米巴牌选择。前者仍要区分阿米巴区域符号移动、虫族计分和盘面分，不能只按按钮标注的分数排序。

候选只在已知粉色痕迹之后剩普通补牌、且没有额外电脑／蓝槽、移动、拿牌或新触发器用途时，用原有放置和区域结算原语核算六项的盘面与终局计分。若有已送达任务，比较时纳入已核验的回合末领取。每个菜单只物化自动结算中的首选（虫族粉 2，5 分），阿米巴粉 3 的外星牌分支仍在同一搜索里走原生。自动补牌继续按信息边界遮蔽。优化预演只复制会修改的外星人和白席切片，并复用已计算的资产值。
