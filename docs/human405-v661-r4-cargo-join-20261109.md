回合末证明仅用于单一已送达任务、其他三席已 PASS、无其他结束回合触发或奖励选择的已知状态。它按当时剩余池位精确计算即时领取，再与保留任务比较；即时领取仍可作为回合内的独立行动。第 355、359 步各有 66 个相同类型的结束回合，每个跳过一次结束操作和两种原生选项提交，共省 198 次。独立把每个“领”和“不领”都原生执行：**两根合计 264 个领取结果**的边界、估值、兑现值和准备债一致，原始存档及 RNG 不变。两根全部根排序、数值和首选保持。

进一步尝试压缩已领取后的多步数据收尾：无额外保护时第 359 步到 561 次，但遗漏了仍有正收益的弃牌角标，把“先领”从 280.5 降回 280；此版本明确拒收。只有手上没有这一类可用角标才尝试合并，得到 685、822，冷根完整排名相同；这个额外候选只做了冷根对比，尚未逐条复核其新增合并证明。

未过 256／600 毫秒，不替换生产 V661，不重跑整局。以完成逐条复核的候选统计，放数据、选电脑/蓝槽和选收入已占第 355 步 365 次、第 359 步 237 次；回合内主动完成任务仍有 107、103 次。下一步优先检查这些尾线的可复用范围和主动领取是否确实打开后续用途。
