# 第三轮：化石交付后的数据去向，与教师同起点复核

**化石 06 路线保留最后两枚数据，未在第四轮前两回合追回立即分析的收益。** 另从教师第三轮原生起点交给当前 AI，轮末是 **93 盘面／126 已有资产分、8 钱／2 电永久收入**；教师同一起点按现行规则是 **105／162、7 钱／4 电**。这确认了第二轮资产不同之外，第三轮本身也存在资源取舍差距。

所有第三轮资产取白席 PASS 选牌及下一轮收入前。白席自主时其他三席只 PASS 或做必选；第四轮比较固定保留同一张 B111。已有资产分只计当时已经获得的资产。以下分支不是从标准开局自主进入，正式记录保持 **15／48／118**。

## 化石 06 线：一笔数据确实能留下，兑现时机更关键

在已交付化石、已插电收入的 **116 分、1 钱 3 电**存档，18 个地球目标／公开牌组合都可扫描并用紫 4 发射。原生结算全部只产两枚数据，不增加扇区胜利。三种地球扫描目标分别搭配 B16 或 DLC17 扫开普勒 22，六组拿到额外 2 盘面分；其余停在 116。扫描后白席有 118 分、3 宣传、电脑 4、蓝槽 1、2 池数据、一张虫族 8 和普通探测器。

保留类六组在第四轮都先把探测器用掉，随后并未立即消耗完整电脑；两回合有更多可用数据，但少了虫族 4 所支持的牌和动作路径。换 DLC17 的最好结果只多 1 分、还少一张手牌；另外几个同为 123 的扫描组合四轮同期是 149／216，且有一个首段决定 **209 次／661.712 毫秒**，未提交。不能把同分、同收入的扫描位置或公共补牌状态合并，也没有理由据此改生产选牌规则。

两次扫描路线实际支付：首扫不发射，留下 1 电；两枚数据分别放电脑第 5 格和现金蓝槽得 1 钱；用 3 宣传取公开 DLC17，与虫族 8 一起换第 2 电。第二扫与分析当轮多拿 2 分，但同时用完这两枚数据，没留下探测器，第四轮落后。这处代价来自真实付款，单增扫描次数不能补齐教师的留存。

这版 AI 先后用 DLC32 和阿米巴 7 插两笔钱收入；两次原生菜单都有可插的电收入，但当前固定选牌将其排除。改成电收入确实可行，却会消耗本来可打出或触发的牌，改变下一次分析、环绕和探测器的投入。直接把钱、电的通用权重对调，现有对照没有证明能补齐教师差距。

从第二次收入之后的同一 **68 分、5 钱、0 电**存档，固定先打阿米巴 0、B14 或阿米巴 9，再交回 AI，分别到 88／117、92／121、83／112，均仍为 8 钱／2 电；末段没开出第三次收入。当前实际先弃阿米巴 0 筹蓝 4，末次分析后扫描的两枚数据只填到电脑第 3 格，手中也已经没有收入牌。下一步应在更早的共同钱包里，找能同时留下**第四格的一枚数据与一张电收入牌**的路径；单换首个主行动或只提前选择一次电收入，不能完成第三次插收入。
