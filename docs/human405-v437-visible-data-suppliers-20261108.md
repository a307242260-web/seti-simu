**修正。** 对每张当时已经公开、角标恰为1数据且没有其他收益的牌，各做一次现有固定付款报价，选择净价值最高的可行报价，同分按实例ID；原生公开市场最多三张。付款证明和实际选牌使用同一规则。不增加原生搜索节点、弃牌组合或未知补牌。原生换钱根的获选报价为190，花85输入；付款弃DLC20和B16，留DLC25，阿米巴9供科研，打阿米巴5后领取已公开DLC17。独立从换钱根自主27步仍达116分。全程重放验证正式机器计划、规则状态、会话及RNG，原根未改动。
