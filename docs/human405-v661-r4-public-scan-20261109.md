# 第四轮公开扫描与状态比较

接续[紫 4 和普通移动复用](human405-v661-r4-movement-reuse-20261109.md)。实际 1,287 条前缀中，没有发现完整状态相同且重复执行的同一动作；已经缓存的共享前缀不重复计入。两条最重路线分别从公司行动和角标筹资开始，各有 307、260 个独占搜索节点，没有汇合。把 39 组公开扫描换顺序走原生：9 组不能双向执行，30 组能双向执行但状态均不相同，搜索也没有把任意一组的两种顺序都展开。不同扇区、落点和奖励继续单独比较。

复用 **99 次**公开扫描结算，沿用正式扫描放标、取数据、消耗公开牌和再选一次的逻辑；22 次结束公开扫描保持可选。原生逐条核对会话、事件、合法菜单、完整状态、观察和随机数一致。49 次继续公开扫描菜单，另外 50 次进入紫 4 菜单。

状态比较只在少量字段和组内筛选均相同后，才用旧算法逐字节确认。独立审计 1,164 次身份分配：1,135 个不同完整状态，和原算法一一对应；同组中不同随机数或收入不会合并，信息边界也保持区分。六个冷根的搜索图、全部根排序和首选一致。上述冷测各是单次样本，组内筛选独立省下的时间仍不确定。估值输入审计及五项相关 Node 测试通过。

自主第四轮首决策达到 256 次原生输入门槛，**600 毫秒仍未达标**；教师第 355、359 步仍为 380、358 次。采样显示，资源计划展开约 398 毫秒、观察投影约 155 毫秒，二者包含的工作可能重叠。下一步优先查公司行动与角标筹资两条路线中的资源计划，区分可由资源下界关闭的路径和必须估值的路径。当前候选没有进入生产 V661，没有重跑整局。
