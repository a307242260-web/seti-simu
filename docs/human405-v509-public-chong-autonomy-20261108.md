# 405 分教学：虫族展示牌与取消按同一回合比较

V509 修复一个条件明确的漏判：当前虫族奖励菜单已公开展示牌，领取它只会把下一张补牌变成未知。此前，搜索在领取后立即结束，却允许取消分支继续走完确定的放数据，导致同一回合的选项比较了不同终点。

分析只接受当前原生、同席奖励菜单提供的展示牌号，并在领取后校验新增实例。新的展示和盲抽保持未知。后续动作仍受原有同回合、同一控制人、固定准备和搜索门槛约束。同估值、同已兑现证据时，盲抽不会因为更早关闭搜索而优先。搜索证书版本升至 v407，旧证书不参与这次选择。

[第 214 步的原生对照](human405-v505-r214-chong-and-energy-20261108.md)中，展示虫 9、盲抽、取消估值从 179／179／181 变为 182／179／181；17 次原生输入，换暗牌顺序后完整搜索图不变。较早的历史虫族菜单中，展示与盲抽仍同为 144.5，继续选择已知展示。候选由虫 9 领取点自主完成第三轮，完整状态和 RNG 与独立的固定原生对照一致。

另一个需要独立处理的问题是有目的的宣传换数据。已验证的固定路线能带出两张虫牌、永久 7 钱 4 电，第四轮能实际运回化石；如果第三轮用虫 2 付移动、留虫 7，交付后还能在第三个主行动付 3 钱研究第七项科技，盘面 138、已实现计分 186。这个阶段多用了一次主行动，仍未超过正式 V495 两个固定主行动后的 189 已实现计分。正式第 214 输入仍选择阿米巴，不能把这些固定对照算成新策略的自主成绩。
