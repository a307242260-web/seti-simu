# V(state) 状态价值函数设计（机器人迭代核心，2026-08-17）

本文档是机器人（免电分析盘面 `seti-free-analyze-v1`，目标均分 100）**价值模型蓝图**。
配套搜索方案见 `robot-iteration-roadmap-20260817.md` 第 5 节；校准数据见该文档第 7 节。
本文档定义 V(state) 的完整成分、公式与权重（全部从用户 405 档实测反推）。

## 1. 设计原则（用户口径）

1. **V(state) 编码长线价值**：搜索只展开 2-4 步到"状态稳定"，长线收益（收入复利、
   科技效率、外星进度）由 V 承担——解决"纯暴搜 + 长度限制看不到 50 步后的收益"。
2. **行动二分法**：为后续准备（科技、收入）vs 当下榨取（分数、资源）。V 同时覆盖两类。
3. **收入引擎明确**：orbit 环绕 + place_data 填数据轨（奖励收入牌→插入收入区）。
4. **打牌价值是枢纽**：打牌给免费科技（4/12）、收入牌、移动/登陆/外星标记链。
   对打牌无渴望 → 不标记外星人 → 不开外星人 → 恶性循环。

## 2. V(state) 总公式

```
V(state) = 榨取类 + 准备类

榨取类（已兑现/即时）:
  scoreValue        = 当前分数（直接计入）
  liquidValue       = 钱/能/数据/手牌 的可转化价值（不是分，是手段）

准备类（未来收益，按剩余轮次/发放次数折算）:
  incomeValue       = Σ(收入率增量 × 剩余发放次数 × 单位转化价值)
  techValue         = Σ(科技效率红利 × 剩余行动次数) + 蓝槽收益
  alienValue        = 外星进度（首痕迹→揭示→位置期望 + 外星牌链期望）
  handValue         = 手牌/保留牌的可打效果期望
```

## 3. 各成分定义与权重（校准自用户 405 档）

### 3.1 收入价值 incomeValue

**机制**（用户纠正后确认）：
- `income` 字段 = **收入率**（每轮发放额度），R2/R3/R4 回合开始发放（baseIncome），
  R1 不发。
- 收入来源：公司初始（incomeIncreaseCount 2 = 两次插入收入牌行动，R1 生效）+2c；
  公司 baseIncome c2/e2/1牌/1扫描（R2 起每轮发）；**orbit 环绕**奖励收入牌→插入 +1c；
  **place_data 填满数据轨**奖励收入牌→插入 +1c。
- 所有收入都是"奖励一张收入牌 → 插入收入区 → 每轮 +1 资源"。

**公式**：
```
incomeValue = Σ_key (leafIncome[key] - rootIncome[key]) × remainingPayments × UNIT_VALUE[key]
remainingPayments = max(0, 4 - leafRound)   // 回合开始发放：R1 末→3 次，R2 末→2 次，R3 末→1 次
UNIT_VALUE: credits=8, energy=10（与现有 INCOME_UNIT_VALUES 一致）
```

**权重推导**（用户 R1 收入率 6/2 vs AI 4/2，差 2c）：
- 1c 收入率 × 3 次发放 = 3 钱 × 8 = 24 分上限
- 但实际钱要花在行动上才转分，取转化率 0.5 → **1c 收入率 ≈ 12 分**（R1 时）
- 现有实现 `incomeValue = Δ×unit×remainingRounds` 缺"复利放大"——用户 R3 爆发
  73 分就是 R1 收入 6/2 撑起来的多行动力。**V 的收入项要在剩余发放次数上再乘
  行动转化系数（≈1.3-1.5，反映"更多收入→更多行动→更多分数"的放大）**。

### 3.2 科技价值 techValue

**机制**：12 科技 = **8 研究（research_tech，花 6 宣传）+ 4 打牌（卡牌效果免费给科技）**。
打牌给科技：R1 purple4、R3 orange2、R4 blue4 等——**免费，省 6 宣传/次**。

**公式**：
```
techValue = Σ(新得科技 tile 的效率红利 × 剩余行动次数)
          + Σ(蓝科技槽位收益 × 期望放置次数 × roundWeight)
          + (打牌来源科技额外 + 宣传成本节省)
```

**权重推导**：
- 蓝科技：blueTechScore 40 分（4 蓝槽 × 8 次放置 × 5 分？用户 blue2 槽 8 次）+
  研究 bonus 30 分（10×2 + 2×5）。
- 效率红利（橙/紫）：研究 orange 后发射/移动降价、purple 后扫描/分析降价——每轮
  省资源 × 未来行动次数。**现有实现只有"每轮固定值×轮数"，没有效率红利**。
- 打牌免费科技：省 6 宣传 + 立即生效。**打牌价值认知直接决定科技获取（1/3 来源）**。

### 3.3 外星价值 alienValue

**机制**（用户 405 档实测）：
- R1-R2 放首痕迹（R2 末 slot1 阿米巴 2 首痕迹）→ R3 双开（阿米巴 step126 + 虫 step219）
- 首痕迹分：slot1 5分+1宣、slot2 3分+1宣
- 揭示后放位置：3-5 分/位置 + 盲抽外星牌
- 外星牌效果链：chong_3（移动→登陆→标记 15分+2牌）、chong_6（登陆 13分+扫描）、
  amiba（精选牌/数据/宣传）

**公式**：
```
alienValue = Σ(未放置的首痕迹期望分)            // 三色齐→揭示
           + Σ(揭示后位置期望分 × 剩余轮次)       // 位置分 3-5
           + Σ(外星牌效果链期望 × 手牌中可打外星牌)
           + 首痕迹归属竞争价值（先手抢 slot1 5分 vs slot2 3分）
```

**权重推导**：用户 R3 单回合 +73 分（外星双开 + 3 科技 + 收入升级），其中外星贡献
约 40-50 分（首痕迹 8 分 + 位置 ~20 分 + 外星牌链 ~15 分）。**放首痕迹的 V 增量 =
首痕迹分 + 揭示进度价值 + 位置/牌链期望**——现有实现只有 traceValue = Δ×5，且
只在"已揭示"后才有位置选项。

### 3.4 资源流动性 liquidValue

```
liquidValue = availableData × 4 × 0.5   // 数据→填槽/分析转化，折半（预期未必全转化）
             + 0                        // 钱/能/宣传不计入（手段不是价值）
```
（2026-08-18 修复根因 1：原公式 `credits×8 + energy×10` 把资源库存按固定单价计入 V，
花 1 钱 = -8 惩罚所有花钱动作（launch/scan/打牌全负），让唯一"不花钱"的 quick_trade
霸榜（白色 86→14，29 次 quick_trade）。资源是**手段**不是价值——通过"能解锁什么"
（收入复利/科技效率/外星进度/即时分）间接体现；钱/能/宣传 0，数据保留 0.5 折半
转化期望（填槽/分析有明确未来路径）。）

### 3.5 手牌价值 handValue

```
handValue = Σ(手牌可打效果期望 × 0.5 + 保留牌可打效果期望 × 0.25)
           效果期望 = 免费科技(30) + 收入牌(8×剩余轮) + 免费发射(6) + 免费登陆(8)
                    + 移动(3×点) + 外星痕迹(6) + 卡面资源(低单价)
```
（2026-08-18 修复根因 2：原公式 `(handCount + reserved×0.5) × 6` 固定 +6/张、不看
卡质量与获取路径——"任何获得 1 张牌"都 +6（quick_trade 用 0 价值资源换卡 = 纯赚）。
手牌价值应来自**能打出的效果链**（按卡面 buildPlayEffects 估算），并按打出概率
折半（手牌 0.5 / 保留牌 0.25）。这是"打牌价值认知"的落点——V 让 AI 看到打牌的
真实效果链。）

## 4. 与搜索结合（V 引导的反事实搜索）

```
决策点:
├─ 专用决策（初始选牌/终局标记/控制）→ 现有规则不动
└─ 主搜索（所有动作都进，不分桶）:
    1. 浅搜索: 每动作 depth 4-6，真实规则执行
       - 展开顺序 = V(branch) - V(root) 优先级（不是目标 gap）
       - 所有动作都试，maxNodes 预算内
    2. 叶价值: leafValue = actualScoreDelta + V(leaf) - V(root)
    3. top-K 深搜验证: 对 V 增量最大的 1-2 候选做 depth 15 真实深搜
       - 验证长链真实可达、无 hidden barrier 破坏
       - 若深搜结果与 V 估计偏差大 → 用深搜结果修正
```

**三处介入点**（对应现有代码）：
| 位置 | 现在 | 改后 |
|------|------|------|
| 叶价值 `leafValue` | 线性外推(tech×轮数, income×轮数) | `actualScoreDelta + V(leaf) - V(root)` |
| 分支优先级 `getBranchPriority` | 目标 gap 排序 | V 增量排序，未绑定动作也有优先级 |
| 根动作 `selectSecondaryAgentRootActions` | 只放行绑定目标动作 | 去掉门控，全部动作进 |

## 5. 可证伪验证

1. **覆盖指标**：unresolved 比例下降、各 family 都有评估（不再只有绑定目标的有）。
2. **行为指标**：AI 开始打有长链价值的牌（b_117/外星牌）、放外星首痕迹、
   主动 orbit/填数据升收入、R1 研究 2+ 科技。
3. **全盘对比**：baseline（白色 86、均分 64.3）→ 新版本。逐项对比：
   分数、行动族分布、外星人时间线、收入率轨迹、科技来源（研究/打牌占比）。
4. **权重回归**：任何权重调整不得破坏测试契约（`incomeValue 54`、卡角 pub 0→1
   不得归因、"钱/电/宣传/数据/手牌库存不得冒充分数"等）。
