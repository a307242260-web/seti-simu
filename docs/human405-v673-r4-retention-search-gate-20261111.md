扫描候选延续已有的公开扫描结算：当固定的行星扇区选择后紧跟已知公共扫描菜单，直接用正式规则构造该菜单；B9 已经跨过公共补牌、且不再补牌的末段，只复用一次扇区扫描和原定结算。遇到无法证明的后续回落原生路径。B111 的 78 次公共扫描前缀和 104 次 B9 末段、B32 的 72 次和 96 次，共 350 次逐条与正式输入对照。已核对保存状态、实体编号、规则 RNG、待处理菜单、可观察屏障及选项；没有隐藏读牌替代、没有丢掉任一合法扇区。两根的完整搜索图、候选、值和获胜首步保持一致。它减少了原生输入，搜索图仍相同，所以不足以达到门槛。

剩余的主要膨胀来自可并列的三个准备目的：拿蓝槽电、在电脑四号槽插收入、公司换牌。它们的不同顺序重新打开主行动，水星登陆在 13 / 12 个准备态下各自执行，其六个黄色痕迹共用掉 78 / 72 个原生输入；还生成 781 / 754 个资源计划边，其中多数是扫描、电脑和蓝槽目标。内存与 CPU 记录显示，即使减少原生输入，复制状态、构造身份和计算计划仍占时间。

关闭换牌会删掉一条有价值的线：先用蓝槽拿电，再用 DLC25 插收入，然后用 B16 换 DLC20，把它付给水星路线，少做一次钱换电。登陆后的任务又取回 B16。两个早期的「换数据牌凑分析」分支目前会重新展开包括扫描、研究、登陆在内的全套主行动。试验绑定为明确的分析目的后，仍保留该分析路线及上述获胜路线，但没有达到 600ms，亦不能证明所有被取消的旁路在其他盘面无价值。仅禁早期换数据牌及仍可先插收入时的早期换移动牌，也只有 B32 单次过门槛（B111 152/674ms；B32 162/533ms），因此没有采用。
