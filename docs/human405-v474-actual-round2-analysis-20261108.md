# 405 分教学：V445 第二轮末分析时机的回查

正式 V445 第二轮最后一个主行动（第121输入前）已有电脑4格和2池数据。原轨迹填第5、6格，免电分析并取第二物种的蓝痕迹，然后PASS。对照从同一存档固定原B101选牌，比较立即PASS、先填满再PASS、原轮分析；再走相同的第三轮扫描、发射移动和DLC31火星登陆。原23输入开局的已接受前缀已重放，正式第二轮PASS前的完整状态与登记检查点一致。

第三轮第一主行动本身沿同一公开扫描及探测器路线。提前分析清空蓝槽，原轨迹可以在该回合重新放数据领公开DLC31；延后分支原蓝3仍被占用，故在同一回合用已知公司换牌得到同一张DLC31。它仍可完成同一火星登陆、揭示同样三张阿米巴初始牌，但电脑尚满，不能在登陆回合插B101。第三个主行动用延后的分析，并在同一回合填回四格插B101；这占用了原轨迹用于DLC19扫描的主行动。同一已知目的下，第二轮提前分析的主要价值是**清空蓝槽、提早一回合插收入、腾出第三轮主行动**，不止是当轮多3分。两条延后分支在第一次扫描后补齐相同电脑状态，之后结果一致；没有比较延后后完全不同的第三轮主行动安排或搜索全局最优。
