## 经验教训

### 1. 行为正确性优先于均分，行为义务是硬判据

均分上升若伴随资源振荡、借用遥远收益或循环转换，一律否决（绿色玩家连续 14 次钱电互换
的例子）。沉淀为通用判据：**一切资源手段（quick_trade / card_corner / place_data）必须
直接解锁原本不合法、或严格缩小明确目标缺口的正式代理**；转换后第一项非转换代理必须是
转换前不合法、转换后才解锁的标准行动。

### 2. 目标在前、手段在后，从动作反推目标全部失败

v22（从转换向外找目标）、v23/v24（只给 quick_trade/place_data 加目标标签）、v45
（从 quick_trade 动作反推目标）全部失败或回退。正确结构：**正式目标（goalId）是搜索的根，
所有资源手段统一提供 `state → gap` 转移**；`goalId` 保存结果、`planId` 保存路线、
`resultGoalIds` 记录一次物理路线可同时兑现的结果集。

### 3. 预算与评分不偷工

128 已完成目标节点 / 15 结果目标深度 / 4096 物理执行保护恒定；no-beam；不设固定分、
不计库存、科技按剩余轮次衰减、终局叶只保留正式终局分。**被截断的搜索必须标记
incomplete / low-confidence，不得把半截状态伪装成完整叶**。10 秒单次决策是失控保护，
不是通过缩预算达成的目标。

### 4. 显式性能近似必须公开并带诊断计数

- 首个结果目标全搜、后续只选正式资源下界最小目标 → `targetSchedulerPrunedCount`；
- 目标内等价弃牌/槽位稳定保留一个代表 → `targetEquivalentChoicePrunedCount`；
- 公共牌扫描触达绑定扇区优先、否则取最低要求代表 → 显式声明为性能近似。

这些是“回退状态”，不是目标设计；后续实现不得把“选最便宜目标”或“跨目标 top-K”当作正式剪枝。

### 5. 剪枝必须可证伪，不冒充完备

三类可证伪剪枝：① 目标资源不可达（乐观上界证明）；② conditional 行为等价（完整 committed
state + 下一 action 全字段相同才合并）；③ 同目标资源支配（同 root、同 target、同完成深度
下逐项 Pareto）。完成态支配以 `rootActionId + goalDepth + targetId` 分组，**不同目标不得
互相删除**；同一目标的不同 plan 可以比较。禁止把非等价 conditional 固定为一个选项。

### 6. 覆盖不变是性能改动的硬门禁

每次性能优化以 executed / expanded / pruned / leaf / root target 等指标逐项一致为验收，
任何减少目标、路线或 conditional 的方案一律回退。先削复制成本（为读版本号克隆整棵
committed state、未消费的默认 projection 分别带来 −41% / −15% 收益），再动结构；
Proxy COW 原型被规则域 38 处原生 `structuredClone` 卡死（`DataCloneError`），整体撤回，
必须先迁移统一 snapshot 原语。

### 7. 隐藏信息边界：reveal 后新身份保持 opaque

公共牌补牌、盲抽、外星揭示、科技 bonus 翻开在决策时均未知。正式 executor 补牌时上报
`hidden_card_reveal` / `hidden_card_draw` barrier；搜索继续，但新身份不得用于建立打牌、
卡角、定向扫描或物种能力路线，只能按数量作通用支付。固定 RNG 只保证可复现，不授权
Policy 读取本局未来信息。

### 8. 单席位规划，对手 fail-closed

反事实只规划本席在当前轮内的连续行动机会，**不执行、不预测、不读取对手行动 / PASS /
手牌 / 预留牌**；对手顶层 action 与 conditional 一律 fail-closed。focal 未来 PASS 在第一个
正式 PASS Decision 边界形成叶，不提前选预留牌；该近似结果偏乐观，必须显式声明。

### 9. 报告与诊断是归因工具，不是装饰

单节点搜索树（`--focus-decision N`）、决策现场、目标簇展示让慢决策可归因。决策 #320
诊断（11.69s）揭示真实爆炸模式：`放置数据 → 快速转换 → 扫描 → 选卡牌 × 外星人痕迹槽 ×
公共牌组合`被完整执行后才被淘汰——大量执行服务于最终被支配的路线，这是后续宏步与
DP 缓存候选的直接证据。

### 10. 流程纪律

- 顺序固定：单次 Decision benchmark → 固定盘面 → 完整局报告；
- 每轮一个结构候选，均分严格上升且行为正确才保留，否则回退；
- 行为失败与性能失败分开验收，不得互相掩盖；
- 策略版本号与 full-flow fixture 同步提升（当前 `seti-heuristic-policy-v26`）；
- 调权重不得改变目标可达性 / 路线枚举 / 节点预算 / 剪枝集合。

## 尚未交付
