# 第四轮规则分支：省掉未消费的返回副本

在[扫描痕迹候选](human405-v661-r4-scan-trace-20261109.md)上核对两项纯执行成本。分析分支不读取返回的完整行动日志；只有在受信分支请求略过投影、且没有规则订阅者时，省掉返回副本。状态保存和会话日志照常保留，失败和信息边界仍回传。恢复后的分支可从自己的存档拿到待决输入编号、版本、所有者和此前的信息边界，省掉一次读取检查；正式提交仍验证输入身份、版本和原生合法性。普通宿主、带订阅的分支、以及一次计划内连续执行未重新恢复的路径继续走各自的原生接口。

单次冷测只表明约 13 和 33 毫秒的变化。五个冷根的首选、估值、兑现值、准备债及完整排序一致。分析先行、领取先行、三个教师决策和初始亮牌共 39 个合法输入，逐步对照精简分支与完整分支：原生菜单、存档、会话日志和随机数相同，原根未变；20 个过期决策仍被拒绝；初始亮牌的信息边界仍留在会话。带订阅的分支返回和发布相同的完整事件，普通宿主忽略该精简选项。规则组合、会话、状态存储、模拟装配、分析分支与估值输入审计通过。

剩余规模主要在原生动作重复。第 355 步的 537 次中，放数据及选槽共 144 次，回合末化石任务询问 72 次，回合内主动完成任务 59 次；第 359 步对应 84、64、55 次。下一步按已领／未领、放置后的数据容量和真实新触发拆分，先核对哪些计划能共享，保留领取到账数量和后续用途确实不同的路线。两根仍超过 256 次／600 毫秒，候选未替换 V661、未重跑整局。
