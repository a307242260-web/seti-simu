# 六类选择收束为贪心计划（2026-10-28）

生产搜索v37依次收束付费奖励次数、已确定的前移时机、主行动后补收入、PASS弃牌、蓝色科技装槽和纯正收益奖励确认。科技种类、主行动与外星人痕迹目的仍比较。六项均属于策略范围选择，`isEquivalence:false`，不宣称与完整原生动作树同值。

## 1. 付费奖励

对已知单一、非负资源奖励体，按当前封顶资源计算每付1信用的增量；资金不足时复用已有贪心筹资排序，保护受益牌，扣除筹资损失。边际净收益不再为正就停止，只生成一个付款额度计划。奖励会返还信用/能量、抽牌或包含其他决策时不套用该规则，保留明确的普通决定路径，避免循环筹资或读取未知牌。

额度计划完成准备后，逐次支付由同一确定规则执行，不能再展开付/停组合。实际只提交一次输入；冷恢复依据原生未完队列、当前余额和已知奖励重新选择，不依赖未保存的付款计数。

第3轮样例原有4/5/6额度及牌内付停分支，现只生成付4次的计划。4次真实付款仍经过原生输入端口。

## 2. 前移时机

既有目的移动策略已经判定 `advance-before-rotation` 并选定前缀时，生产搜索只执行该前缀，暂不展开结束turn及其他准备。没有有利前缀、应等待公转的情形沿用既有延后判断。

依据仍是一轮已知公转，忽略其他玩家干预。测试中的前移2步把预计移动成本7降至6；该处候选从移动/结束两条收束为1条固定路线。费用、路径、回放和中断按原生输入执行。

## 3. 补收入

主行动完成后，读取当前可以直接支付的数据、已选收入牌和计算机槽位。对玩家副本调用原生放数据/收入算术，计算即时资源、手牌成本、数据成本、剩余正式轮初收入及已有终局计分联动。盲抽只计已知张数，不读取未知牌身份。

净收益为正便作为固定收入尾部执行；非正移除收入目的，保留其余合法结束/奖励流程。当前数据不足、还需要额外筹资的主行动后收入不纳入该局部尾部策略。主行动前、明确为分析/科技等目标准备的数据仍按目标计划处理，不能把前置收入无条件强制到所有主行动前。

原第3轮登陆后的样例不再比较补收入与结束；提前轮次的正收益对照固定补完。局部预测与真实固定收入链的窗口估值差已直接对照。

## 4. PASS弃牌

手牌上限的原生合法弃牌组合保留，AI按已知牌价、剩余收入和角标用途计算保留价值，保护明确受益牌，固定损失最低的合法组合；平价按actionId。不会因为有15种合法组合就模拟15条弃牌后续。

测试覆盖弃1张时5选1、弃2张时15选1和冷恢复一致。该排序是保牌策略假设，不是完整未来牌价值评估。

## 5. 蓝色科技槽位

每种蓝科技只保留一个版图槽位：优先已有对应计算机数据的列，否则选择距当前进度最近的列，平价按槽号。目录及卡牌赠送科技选择共用该规则，所有科技种类仍保留比较。

第3轮根科技目录由23种“科技×槽位”收束为11种科技，第4轮免费研究的12个合法选择保留10种科技。共享前缀验证同步改为当前目的：全部11种科技仍共享7步准备，实际18输入/19状态，各自保留8步原生路径。旧20槽位组合仅作为历史数据，不驱动生产恢复组合枚举。

## 6. 纯正收益奖励

仅对正式触发结算中全部由非负 `gain_resources` 构成的奖励体固定选择；多项时按当前封顶后的资源增量选一项。未知抽牌、付款、移动及其他效果继续普通决定。调用Residual原生 `queryCardSettlement` 查询真实结算体，在副本上读取，未另写一套任务就绪判断。

第3轮登陆后的免费3分触发固定接受。触发次数消耗、卡牌移出、计分事件仍由原生结算执行；该策略不保证最优保留未来触发时机。
