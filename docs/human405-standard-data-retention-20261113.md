# 标准第三轮：数据时机与末次电收入

用 `94b1215a6` 从已登记标准局第二轮末原生存档重放，到第三轮的规则信封逐字段一致。只更换表中所述的公开选择或付款，其他三席仍只 PASS 和必选；固定输入后的白席由 Production 决定，超过单点 256 次／600 毫秒前停止。以下步骤是正式局的一基输入编号。

- **第 187 步，阿米巴 3 的痕迹。** 先固定其他粉痕或蓝痕，再尽量逐输入匹配原计划。三个替代都只有 1 池，原黄痕后 2 池。第一次分析后是 1 池对 3 池；继续原紫 1 和前三格，在第 201 步连「放置数据」都不在原生菜单。自主收尾最高 99 分、四科技、永久 7 钱／3 电。原黄痕没有消耗保留中阿米巴 0 的粉痕触发；该笔数据在第 216 步仍能领取。
- **第 214／216 步，后一次扫描奖励。** 留在已知物种，换 3 分额外痕迹或粉 2，固定领取同一个已知粉痕数据及 DLC9 宣传，再交回 AI。都可留 3 池进入下一回合，但失去原公开阿米巴 5，末段最多 115 分、六科技（蓝 4 代替橙 1）、永久 7 钱／3 电、无探测器。仅跳过原已知粉痕数据，则留 2 池，末段 116 分，也只有 3 永久电及不同科技；没有证据支持预留这次触发。
- **第 231 步，推迟填第六格。** 先用同一枚数据取蓝槽现金，原下一枚池不花，继续匹配打阿米巴 5、公开拿牌、公司换牌。第 242 步仍留一枚池，但不再可直接分析；交回 AI 后补回第六格，最后达到相同的 118 分、六科技、永久 7 钱／4 电、4 电脑格、同一探测器、空手空池。第四轮固定相同留牌 B111／B32，终局仍是 272／249；和已归档对照的终局规则状态及 RNG 逐字段一致。留池确实可推迟一段，但现行行动会消耗它，并没有形成第四轮库存。
- **第 244 步，末次分析领奖。** 选择展示阿米巴 2 后是一枚已有池，外加 DLC15、DLC17、阿米巴 2 各一枚数据角标，恰好为 DLC25 的第四格电收入筹齐；无多余数据。逐一换三张真实可盲抽牌到牌顶，公开观察、菜单、首选及原报价一致。固定盲抽阿米巴 8 或 4，只有三枚可知数据，收于 115 分，保三张手牌及蓝槽但少 1 永久电；盲抽阿米巴 6 仍恰好四枚，终点 118 分、同科技及收入，但仍空手空池。盲抽不能解决此处留存缺口。

以上把原标准线上可变的数据时机与必需付款分开。最后第四格不存在一枚可直接挪用的盈余；下一步只保留能新增独立数据来源、同时验证不牺牲原收入与科技的候选，不再为同一枚数据重试排列。
