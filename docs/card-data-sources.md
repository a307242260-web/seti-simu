# SETI 卡牌资料源

## SETI Fan Hub

- 中文入口：https://seti.ender-wiggin.com/zh-CN
- 用途：查询 SETI 卡牌内容，包括普通卡牌、公司（组织）牌、起始卡等资料。
- 当前页面能力：可按来源、行动图标、收入、扇区、卡牌类型、文本和费用筛选卡牌；站点导航含“起始卡”和“组织”。

这是第三方资料站，适合用于卡牌录入、名称核对和机制检索。涉及规则歧义、版本差异或实现验收时，仍需与实体卡、官方规则或项目内已确认机制交叉核对。
