# 受限首个主行动的钱电模拟（2026-10-22）

`seti-helios-opening-money-simulation-v1` 由可信端口 `openingResourceOrder` 提供。
这是对当前首个主行动局面逐项核对后的受限证明，不是对任意主行动前状态的资源单调性断言。
与[主行动后证明](ai-resource-dominance-proof-20261022.md)使用相同冻结估值能力、全局覆盖语义和预算。

## 额外适用条件

稳定节点、无 Session、主行动未完成，且满足原证明中的赫利昂公司、无活动事件奖励、
无已揭示外星人、未 PASS/开局、合法资源向量、正式推进会交给另一 owner 且不跨轮/终局等条件。
本证明额外要求：

- 本席没有任何归属探测器，包括非标准棋子；本席没有已拥有科技。
- 所有席位保留区为空。
- 本席手牌仅为 dlc27、b44、b23、dlc22、b48 的子集；未审计的牌立即拒绝。
- 公共牌均为标准 basic / space-agency 牌。

非钱电身份、蓝槽归因与 RNG 完全相同，钱电逐坐标不劣且至少一个严格更多时才可覆盖。
数据标记仅使用[独立证明的向前等价](ai-data-token-equivalence-20261022.md)。

## 准备链与主行动的检查

主行动前可用准备是固定资源交易、标准弃牌角标、放数据及其收入奖励。
无科技时赫利昂不能启动移除科技能力；无本席探测器时移动不能产生新探测器。
标准角标只给宣传、数据、移动及附带分数，计算机4号位只插收入牌；这些准备都不发射探测器。
取得新身份信息时停止，因此在进入主行动前，手牌仍是已审计集合的子集。

| 已审计牌 | 对钱电差的影响 |
| --- | --- |
| dlc27 | 只有零钱电条件依赖能量库存。进入该主行动前没有本席探测器/运输化石，故零能量时奖励数量也为0；跳过与执行零奖励都不改变向前规则事实。没有保留卡或事件奖励观察这一区别。 |
| b44 | 打出后只提供访问金星得宣传、访问木星得数据的触发器，不读取钱电库存。该牌本身不发射探测器，主行动完成后不能再启动发射主行动。 |
| b23 | 处理相同公共标准牌的角标，固定收益相同；补牌产生的信息屏障前停止。 |
| dlc22 | 扇区资格由相同己方信号决定；相同扫描目标与结算收益不依赖钱电库存。 |
| b48 | 相同公开取牌及标准角标效果不依赖钱电库存；新信息在屏障停止。 |

其他主行动为发射、扫描、研究、分析或 PASS；相同固定费用在较富状态也能支付。
实际 main 标记在启动时消耗，后续不能再打 dlc27。
正式代码仅在回合推进时清除 main 标记，本证明已要求推进到另一 owner，届时停止。
后续科技、数据、探测与公开奖励按相同选择执行；能量支付候选保留较穷状态可选的每种方案。
钱包差在相同固定支出/奖励下保持，非终局线性估值的钱电正权重使边界值严格不劣。

本结论仅适用于上述具体模型与准备入口。新增主行动重置、准备发射、额外打牌或这些牌的资源条件后，
必须重新审核；未审计的手牌、科技、保留卡或外星人状态继续完整搜索。
