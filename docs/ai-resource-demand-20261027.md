# 按目标准备资源（2026-10-27）

实验搜索 v33 开启 `resourcePlanning`。兑换和弃牌角标不再作为独立候选动作；先有明确目标及资源缺口，再固定准备流程。只有可行的贪心来源全部失效，或原生效果与弃牌身份有关、不能固定时，才进入绑定同一目标的搜索。此为策略范围调整，记录 `isEquivalence:false`，不声称与原生全部动作树等价。

## 目标、费用与准备

目标包括指定手牌的打出、标准扫描、地球发射、指定科技及蓝槽、一个固定探测器终点、计算机第四格收入/六格分析，以及合法蓝奖励槽。费用、发射容量、科技与蓝槽选项、探测器路线/终点来自 Production 只读查询；查询蓝数据选项时复制玩家，避免修改冻结状态。主行动完成后不再查询已不适用的科技及终点目录。

探测器终点按已知得分、数据、剩余收入与原生费用/路程的净收益选一个，平价比较路费、步数及目标身份；不因需要兑换而重新展开所有目的地。普通未来移动仍保留既有转盘时机比较。指定科技/打牌等目标之间仍可比较。

准备前先计算钱、电、宣传和数据缺口，并检查乐观可达容量；容量只用于排除必定不够的目标，不是可达性证明。保护目标牌和选定收入牌，计算可用移动角标、数据角标、电脑第二格宣传及原生角标倍数。收入牌按本轮以后收入价值排序，取仍能保住所需数据的第一张。

只允许减少缺口的资金来源。先按损失/补缺量贪心，再比较原生输入数和稳定 actionId；损失刻度为钱/电/手牌各 2、宣传 1。它是明确的有损策略，不把不同剩余资源称为等价。钱电兑换、两张牌换资源和资源角标均走原生输入；手牌按印刷成本及目标所需移动/数据角色选定。资金够了立即执行目标，不能继续兑换。数据只为具体计算机/蓝槽义务放置，不作为没有目的的库存调整。

正常资金来源可贪心完成时，不因另一条来源存在触发器而开启搜索。若所有来源都涉及身份敏感奖励，或选出的付款牌会破坏目标所需数据/移动能力，则记录回退原因。回退只保留该目标的付款或效果决定，不能重新开放无目的兑换；付款排除目标牌，确认前复查资源可达容量。没有任何补缺来源则显式记为目标不可行。

## 图、预算与恢复

`resource-goal-plan` 是候选，兑换、付款点击、放数据和目标本身是其原生执行步骤。证据保存目标、每步剩余缺口、准备原因、全部 actionId、回退原因及目标是否完成。多个目标可以共用同一个首输入，根证据汇总其最佳可达结果，候选仍分别记录目标。未完成集合同时记录目标身份，不能用重复的首 actionId 冒充不同搜索节点。

原有完整规则状态、队列和 RNG 身份不放宽；回退另把目标及操作阶段纳入控制身份。固定流程的中间状态不创建新的行动选择图节点，但每个输入和内部状态仍计入全局额度，`nodes=graphNodes+certificateNodes`。预算仍为 256 输入/257 状态/256 前沿/600ms，纯诊断用途；没有提高额度或允许截断后提交。

中断返回空动作、空证书和实际已模拟输入。普通有向图仍保留环与精确去重。已证明的主行动后收益上界、最短完成见证和图灵借用归约继续按前提使用；旧的开局角标/数据局部归约不再覆盖新目标政策。

实际机器每次仍只提交一个原生输入。原子准备完成后的稳定边界从物理状态重新规划，不持有隐藏的长期目标；原生付款/数据 Session 尚未完成时，从其起始状态和已提交来源重建可受益目标。不会为资源流程内部前缀发放依赖未持久目标的复用证书。旧最短收入宏的内部证书在此模式同样禁用，避免其收入牌选择覆盖新贪心规则；普通移动与固定取牌的已验证复用保留。reset/restore 仍重建算法，真实输入、回放和恢复不变。

这也意味着本次没有保证“跨多个已提交原子行动始终坚持同一个目标”；它保证无目的资源操作不进入候选、每次重新决定可复现，原生未完成付款不会重开兑换树。

## 边界

当前仍在信息/其他玩家/终局边界停止，未改成完整 turn/round 搜索。公司专用取牌、外星专用角标和未建模卡牌内部付费诉求，尚没有完整的资源需求目录；不能宣称所有这类准备路线已经覆盖。已合法启动的公司/卡牌条件决定仍执行原生搜索，不通过“多囤钱电”猜测其未来需求。

指定牌的重复钱换奖励已能生成有限的预付款额度目标；尚未把所有复杂牌、公司或外星符号效果统一拆成需求。付费普通取牌继续使用既有明确诉求与固定选牌缓存。
