# 主行动后收益上界与最短完成见证

搜索v29在默认V、`postMainPruning`下增加两种不同的证明：
`postMainValueBound`只提供乐观收益上界；`postMainOptimalPlanSpec`只有在能实际达到该上界、
并同时证明输入数最少和actionId平分代表时，才允许省略其余继续路径。
上界本身不能用来返回动作。精确状态身份、正式边界、默认256/257/256/600ms预算均不改变。

## 规则闭包与上界

起点必须是无Session、主行动已完成的稳定本席状态，且满足已有已知模型钱电闭包。
公司仅限图灵或无主动能力的异星实验室；下一轮内必须交给其他席位。
排除蓝科技/蓝奖励归因、特殊探测器/化石运输、Pluto、任务、保留牌终局公式、历史访问事件、
额外公司流程、就绪或已揭示外星人，以及未知行动、模型和DSL选项。
分数低于最早金标阈值且没有本席金标；剩余访问奖励不得增加score。
手牌角标和收入必须是审核过的标准0/1/2，电脑已放位置必须是原生连续前缀。
这些检查保证没有未计入的取牌、免费移动、额外放置奖励或中途计分来源。

V采用既有默认线性模型。普通移动每步至少支付1V（电或一张移动角标牌），原生到达最多增加0.5V；
橙2仍保留真实收益。一次访问最多消费一个候选触发槽，不能同时领取全部匹配牌的奖励。
剩余槽先用Production `ensureCardEffectState`规范消耗记录；旧模型消耗不能删除未来奖励。

令每个访问槽的奖励价值为r，N为所有剩余访问槽数，D为任一本席探测器到任一正剩余收益目标
所需移动的乐观下界：8列环绕曼哈顿距离至少1，忽略占位、小行星额外费用和轨道要求。
可达目标与匹配使用正式太阳系和触发器匹配器；不会重写规则移动执行。

```
movementUpper = max(0, sum(max(0,r−0.5)) − 0.5×max(0,D−N))
```

只在正式目录存在目标时计入正剩余收益。N保守保留无净收益和不可达的访问槽，避免漏算中途数据
补偿。没有正收益目标或没有本席探测器时移动上界为0。此界允许不可实现的组合，所以只能高估。
抽牌/精选在首次新信息结束窗口，须核对可用牌堆足以兑现最大的单次奖励；不能以空堆规则失败为剪枝。

电脑第4格只有一次插收入机会。令n为已放格数、k=4−n、R=4−当前轮，c为即使乐观使用全部
未来访问数据后仍至少需要的手牌数据角标数。电脑库存上界计入当前数据、全部数据角标和全部访问数据。
库存够4、收入格未填、且角标后仍有手牌作收入时：

```
incomeUpper = max(0,R − 0.5×k + (n<2 ? 0.5 : 0) − 0.5×c)
maximumValueIncrease = movementUpper + incomeUpper
```

c个角标每次损失0.5V，放k份数据损失0.5k，第2格原生宣传增加0.5V。
插收入即得一次资源/盲抽，抵销消耗手牌的1V，剩余收益为R。
移动获得的数据已在移动奖励内计值，额外插收入价值只计上述增量，避免重复计算。

普通搜索仅在**实际已到达边界的最高V严格大于当前V加上界**时剪枝；同值分支继续探索，
保留较短路径和actionId平分。省略节点记录完整bound、上界、实际见证和proof，V保持null。
纯付款选择起点关闭这两种全局捷径，继续保留每个实体付款出口的精确证据。

## 实际达到上界与最短输入

仅当movementUpper为0时尝试构造计划：

- incomeUpper为0：正式end_turn一次达到当前V，也是最短完成路径。
- incomeUpper大于0：必须完成电脑第4格收入。若当前库存不足，只在实际所需数据角标数恰好等于
  上界中的c、手牌足够且保留收入牌时使用。未来访问数据可能减少角标数而尚未兑现时不取得权限。
- 第2格宣传奖励仍未取得时，须有容纳该1点宣传的空间；宣传已满则只能保留为乐观上界，
  拒绝最短计划捷径，继续普通搜索。已正式放过第2格不受此限制。
- 先用c张数据角标，再逐份正式place_data和唯一电脑目标选择；插收入，现金收入后再end_turn。
  若可保留盲抽收入牌，则窗口提前在该次新信息结束，严格少一次输入。

输入下界为 `c+2k+1+(盲抽?0:1)`。每份数据必须经过两次真实输入，角标至少c次，收入选择1次，
非盲抽还要交接1次。移动不能替代其中必需输入；其他交易和准备增加次数或降低V。
在最短候选中先执行字典序较小的card_corner，再place_data；角标按当前actionId排序，但必须保留
足够的数据角标和可用盲抽收入牌。收入也从当前合法集按actionId选择。
每个内部前缀的后缀具有同样的V、最短剩余输入及平分代表，因此可以单独复用。

全部步骤经`expand`执行Production合法descriptor；提前出现信息/owner边界、合法集结构改变、
步数不符或最终V未达到上界时显式失败。没有虚拟动作、模拟收益或自动提交真实Decision。
共享机器玩家仍每次只提交一个真实输入。

## 计费、证据和恢复

`diagnostics.nodes = graphNodes + certificateNodes`。每个宏内部前缀都计入全局节点额度，
最终边界保留为普通图节点；正式输入按真实次数收费。执行前还保守预留内部状态的前沿额度。
这不是逐根leaf cap、深度截断或beam，不能凭预算截断宣称必要探索完成。

宏边保存全部steps、真实cost、边界见证和最少输入证明。内部前缀最多32条，分别绑定精确状态、
RNG、队列、完整合法信封及模型。它们不伪装成额外展开的图节点；内部非选中动作值为null、
not-executed，并引用达到上界且最短的证明。既有选择/借用宏不会因此自动取得内部复用权限。

watchdog在宏每步前检查。中断时记录已执行模拟输入、证据状态数、steps与原节点未完成动作；
没有可提交动作或证书。全局预算不足时也不能跳过计费直接使用计划。
reset/restore仍丢弃算法实例和token；内部下一步虽合法，其他状态依赖改变时仍拒绝复用。
