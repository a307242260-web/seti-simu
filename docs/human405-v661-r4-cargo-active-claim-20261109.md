# 第四轮主动领奖：只有能打开后续用途才另走一条线

基于[带角标的数据收尾](human405-v661-r4-cargo-data-tail-20261109.md)，把两个冷根合计 210 条主动完成任务的搜索边逐一按规则和用途拆开。两个根各有 48 条运输领取在主行动之后，原图领完只剩结束回合，且已有同回合结束时领取的证明。

隔离候选只在已有回合末领取证明、电脑和蓝槽无可用收益、同一已知奖励后的钱包不会打开拿牌或移动目标时，复用回合末领取。已开始但还没走完的移动不能跳过；已到达的目的地仍以原移动策略核查。主动领取能打开蓝槽放置、补收入或其他真实用途的分支保持。根的直接领取选项仍可比较。

每条被合并的来源都从原生存档分别执行“主动领→结束”和“结束→确认领”，两根合计 **96 对**均到达相同的生产搜索向前规则身份，含同一随机数、资源、牌与待决状态；也核对原图主动领取之后只有结束动作。原搜索根不变；完整根排序、估值、兑现值、准备债、首选保持。第 314、351、354 步仍是 6、10、2 次。

第 355 步剩余放数据及选槽合计 244 次。其中 36 次选蓝槽 3、26 次选电脑第 5 格（24 次发生在主行动之后），两类连同启动放置约 124 次输入；电脑第 1–4 格仍各选了 11 次。第 359 步剩余放数据及选槽 104 次，34 次选蓝槽 3。两处扫描引发的外星人痕迹选择均为 42 次。下一步优先核查电脑第 5 格和蓝槽 3 的固定前缀，把仍会引出公开选牌或痕迹任务的分支保留。
