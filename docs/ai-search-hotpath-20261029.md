# 搜索只读热路径优化（2026-10-29）

本轮保持搜索v37的全部策略、目标、状态身份、估值字段和预算，优化移动时机预览的复制与重复计算。最终八点为8/8：第3轮156次原生输入、约582ms；第4轮200次、约594ms，计入打开根节点的墙钟时间，均完整闭合。

## 定位与修改

原版在相同256输入、257状态、256前沿、600ms预算下做CPU采样。structuredClone约占26–31%的采样，最大复制来源是每条移动前缀的整份状态复制，其次是投影中公转时机计算、Session恢复等。采样本身有开销，不作为性能验收。

1. 公转/路线预览只独立复制实际可写的太阳系、棋子及玩家资源。其他经过验证的原生切片只读共享。继续调用正式公转、碰撞、推动宣传奖励及费用查询，不另写几何结算。冻结原根使意外越界写入直接失败。
2. 移动时机缓存由Production提供 `plannedMovementTimingKey`。完整太阳系、棋子、行星、外星状态、玩家非经济事实、turn、目标、路径和免费额度入键；手牌、收入、资源和数据标记不影响这个纯时机结果，排除在该计算键之外。经济可达性、奖励价值和当前支付能力仍由目的策略按每个真实状态重读。
3. 分析层复用原生完整投影已经隔离并冻结的字段，遮蔽产生的新包装对象仍冻结。省去第二次完整观察复制，保留全部观察字段、信息边界、根与兄弟分支隔离。

缓存仅复用几何计算结果，不合并游戏节点。完整状态、Session、RNG及目标控制仍决定搜索身份；没有删减前置收入、不同获取科技途径或任何必要决策线。计算缓存每端口至多64条，close后清理。没有修改正式输入/回放/恢复的复制契约。

## 等价与失效验证

优化前捕获12个原生路线时机结果和4份完整观察哈希；优化后逐项保持一致，冻结源状态及正式RNG均不变。资金、收入、手牌和数据变化可复用时机；旋转、棋子、玩家科技与失效状态、当前turn、当回合移动修正、免费额度变化必须失效。

单独复制切片尚未使八点达标；加入计算依赖键后两个晚期搜索均闭合，但第4轮含开根约602ms，仍记7/8。再去掉已冻结观察的重复复制，最终单次八点8/8。所有中间记录保留于检查点；没有重跑同版本相同实验来挑选通过结果。

第3/4轮最终缓存命中与未命中数、观察生成开销、原生动作与全图证据见[验证汇总](../reports/ai-foundation-20261023/search-hotpath-final-20261029-v1.json)。时间属于单次顺序Node进程，存在JIT、宿主负载和采样差异，不据此声称统一提速比例或棋力改善。第4轮距离600ms门槛较近，仍需后续扩大局面覆盖与整局验证。

本轮没有完整终局成绩，也未完成180秒整局验收。此前decisionObs对aomomo冻结对象的写入审计失败未在本轮修复，独立估值检查与该历史失败分别报告。
