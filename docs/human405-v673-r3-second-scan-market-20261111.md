# 第三轮第二次扫描：为什么保留市场上的 DLC17

开普勒 22 的最后一枚信号可以用 DLC24 或 DLC17。两者都完成同一个扇区；用 DLC17 也能拿到同一粉标、阿米巴 5、阿米巴 0 的触发数据和 DLC9 任务奖励。科技、收入、即时资源、手牌、扫描结果和 RNG 都相同，但市场不同：标准留下 **DLC17／DLC20／DLC16**，另一条留下 **DLC16／DLC20／DLC24**。不能按落点或即时分数把它们合并为同一状态。

实际搜索把 DLC17 排除在固定扫描计划外，原因是已有“保留公开数据角标”规则。在此存档，白席持有电收入牌、没有数据角标，DLC17 是这个扇区可用的公开牌中唯一可弃出数据的一张。仅在隔离副本取消这一保留判断，固定选牌就由 DLC24 变成 DLC17；两边各 **18 次**、当前回合估值同为 **168**。这直接核验了选择来自固定准备规则，既不是规则不允许 DLC17，也不是估值已经给替代牌报了低分。

从同一个扫描菜单用 DLC17 后，改变后续当时实际可见的橙 1 奖励、阿米巴 5 取牌和公司换牌时机。25 条第三轮路线均合法完成。第三轮终点统一取 PASS 选牌和下轮收入之前；接续只固定相同的保留牌，其余白席自主，其他三席只 PASS 或做必选。

两条等分路线也留住了相同的六科技、电脑四格、在 (4,2) 的普通探测器和 1 现电。它们仍要把 DLC15、DLC14、阿米巴 2 的三枚数据角标全花掉；市场变化没有新增第四轮可用的手牌。留三牌的对照也没补到第四份永久电。结果支持现有固定规则在这处保留 DLC17，尚未证明应推广到其他扫描或牌序。下一处应查分析前能否多取得一份可用数据，避免把末次补格变成纯手牌消耗。

八条接续均为自然终局，所有已提交的自主决定在 **186 次／397.768 毫秒**峰值内。另独立重放 **1,551 个原生输入**，核对各分叉、完整终点及八个正式规则终局。仅归档证据，生产策略、V2 正式结果和 V41 基线不变。
