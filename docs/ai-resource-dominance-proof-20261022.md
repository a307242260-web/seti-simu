# 主行动后钱电支配的受限证明（2026-10-22）

`seti-helios-post-main-money-simulation-v1` 只用于当前 Production 规则中一类受限状态。
它证明较富状态能够模拟较穷状态的后续路径；两个状态并不等价。
默认关闭，搜索调用必须显式设置 `resourceDominance: true`。

## 适用条件与状态比较

可信分析端口 `postMainResourceOrder(node)` 检查以下全部条件，否则返回 null：

- 稳定节点、无 Effect Session，当前席位已经完成主行动，尚未 PASS，也不在开局流程中。
- 本席保留区为空，当前回合无活动卡牌事件奖励，没有已揭示外星人。
- 公司仅为赫利昂联合体：主动能力是移除非蓝科技后插收入，被动仅为三色奖励槽。
- 手牌全部来自标准 basic / space-agency 目录，不包含外星牌或未建模牌。
- 钱电与蓝槽钱电留存都是合法非负整数，留存不超过实际库存。
- 用正式 `advanceTurnAfterPlayerAction` 预演，结束回合会转给另一席位，且不跨轮、不终局。

比较键保留完整向前规则身份与 RNG，仅把本席的钱、电两个字段归零。
弃牌堆仍采用已经单独证明的排列等价，其他数组和规则字段不省略。
算法只取得不透明组令牌与本席公开钱电向量，不能取得隐藏状态键。

同组 A 支配 B，当且仅当 A 的钱、电均不小于 B，且至少一个严格更多。
蓝槽留存不能忽略：正式支出先扣蓝槽留存，后续归因可能区分它。
该字段未进入标准席位观察，因此在可信身份中要求精确相等，不向算法额外披露。

## 后续路径模拟

主行动后不能再次启动打牌、发射、扫描、分析、研究、环绕或登陆主行动。
`mainActionCompleted` 只在正式回合推进时清除；此处预先排除了推进后仍由本席行动的情况。
因此，手中的 dlc27 零能量牌不能在本窗口重新打出。
本席没有保留区，dlc28 零钱电任务及卡牌触发器也不会进入本窗口；
赫利昂主动能力把手牌插入收入，并不执行该牌的完整打出效果。

当前剩余规则逐项如下：

| 入口 | 模拟较穷状态的同一选择 |
| --- | --- |
| `actions/quick-trades.js` | 固定费用只增加可负担选择；固定奖励相同。两张弃牌保留相同实体与正式点击。取牌遇到信息屏障停止。 |
| `effects/residual-domain-session.js` 的标准弃牌角标 | 相同牌的宣传、数据、移动与附带分数相同。移动选择继续按正式规则执行，保留较穷状态可支付的同一方案。 |
| 同文件的赫利昂主动能力及 `industry/abilities.js` | 相同非蓝科技、奖励槽和收入牌选择不依赖钱电是否为零；科技移除、收入及立即奖励相同。 |
| `effects/science-session.js` 的免费放数据与奖励结算 | 可放数据和奖励由相同数据、科技、槽位决定。后续资源费用为可负担性条件；标准科技奖励不读取零钱电条件。新身份信息在屏障停止。 |
| `effects/probe-turn-session.js` 的移动与支付结算 | 相同火箭和方向产生相同事件。能量与移动牌的每种合法支付都保留，较多能量不会强迫改用另一方案。 |
| `end_turn` 及回合末公开结算 | 当前正式终局公式不直接按钱电库存计分；标记机会、公开分数与揭示机会相同。到另一 owner 或信息屏障停止，不继续规划下一回合。 |

同一步的固定钱电支出和奖励保持实际钱电差；蓝槽扣除使用
`max(0, 留存 - 费用)`，保持两状态留存相同。
相同事件对其他席位的触发条件相同；若出现其 Decision，则同样在 owner 边界停止。
没有已揭示外星人、活动事件奖励或本席保留卡，因此没有零钱电敏感任务或牌效混入上述链。
对同一选择序列归纳，B 的每条边界路径在 A 均有资源不劣的真实路径。

本证明与规则来源绑定。若增加主行动重置、快速打出、钱电库存条件、强制按库存改变的支付或奖励、
新角标类型或公司效果，必须重审适用条件与测试，不能沿用资源多少的直觉。

## 估值与搜索证据

只接受 `createStateValueEvaluator(seatId, options)` 创建的冻结线性估值函数，
要求钱和电权重都严格为正，席位与根一致。配置在创建时复制冻结，模型键包含版本、席位和权重。
任意自定义函数、错误席位或零权重都显式拒绝使用本证明。
这是相同其他事实下的单调性依据，不是启发式收益上界。
本适用窗口不抵达终局；边界公开钱电没有被信息遮蔽回根值，因此严格资源差使边界估值严格更高。

搜索对被支配节点记录 `proof-pruned`、支配节点和钱电差额，取消其尚未执行的展开。
已经执行的边保留；不增加虚构边，也不把较富状态的值赋给较穷状态。
较富节点若后来被更富节点覆盖，证明链继续保留；剩余必要节点遇到任何全局预算仍返回 incomplete。

此为全图最优值的覆盖证明，各根动作的值只能标为已取得的下界，不能宣称逐根精确值。
完整图闭合时，最终动作仍来自真实已执行路径。
以纯选牌部分为根时关闭本剪枝，保证跨真实点击复用证据仍包含所有出口的精确值。

## 验证与实际收益

真实 Production 前缀：固定输入先打出首张手牌，再两次弃两张换信用，得到无手牌的主行动后窗口。
关/开剪枝均完成整个窗口，最佳动作均为 end_turn、估值均为34，真实根与 RNG 不变。
输入318→163，唯一节点300→156，5个节点带支配证明。
同进程依次测量638.74/308.40 ms，差额包含预热，不能当成冷整局提速比例。
证据见[局部完整对照](../reports/ai-foundation-20261022/post-main-resource-benchmark-v2.json)。

反例测试覆盖主行动前、同席下一回合、保留区任务、活动事件奖励、其他事实不同的比较组、
不匹配的估值函数、预算未完成与选牌证据禁用剪枝。

[开局主行动诊断](../reports/ai-foundation-20261022/operator-profile-v5.json)执行4096次输入：
43个支配剪枝，但仍有1581个未完成节点，耗时6.98秒。
这没有通过主行动完整覆盖或单决策性能门槛，不能据此运行搜索版完整局或宣称整局180秒达标。
