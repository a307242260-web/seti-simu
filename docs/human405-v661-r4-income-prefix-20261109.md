# 第四轮电脑收入：复用已知付款并保留蓝槽真实取舍

基于[蓝槽 3 核验](human405-v661-r4-blue3-20261109.md)。第 355 步电脑第 1–4 格之前各走 11 次。8 条已无运输任务的路线，都会先固定完成四格电脑和同一收入牌；收入后，原生策略允许拿 1 分＋1 数据的角标给第一段蓝槽供料。旧数据预演在场上有探测器时只看纯数据角标，无法收束这 8 条路线。其余 3 条尚有已送达任务，领取时机与随后的蓝槽资金仍是实际差异。

候选在已领取化石且现有固定数据证明适用的状态中，复用真实资源策略的已知角标排序，并检查触发器与原始可见卡。完成收入和第一段蓝槽后，对第二段进行实际比较：8 条路线的蓝槽 2 均有合法供料，但相对直接结束估值、兑现值、准备债差都为 0，要多 3 个原生输入；因此结束，留住供料牌。未使用有损的“继续放所有数据”或额外搜索弃牌组合。

第 355 步电脑第 1–4 格的原生提交各由 11 降到 3 次，全部候选排序、估值、兑现值、准备债和首选保持。逐条原生复核 54 条固定尾线；第 355 步新增 8 条收入尾线，各自对比多放蓝槽 2 和直接结束，结论一致，原根不变。第 314、351、354 步仍是 6、10、2 次。当前两个重根仍超过 256／600 毫秒，没有替换 V661 或重跑整局。

剩下 3 条电脑收入之后的最优见证是“领取后再走蓝槽”，不能套用已经领取的证明。两处扫描触发的外星人痕迹选择仍各 42 次，另有真实多任务选择；下一步拆哪个痕迹奖励会改变后续资源目标，避免在同一阶段重复作无关的选择。
