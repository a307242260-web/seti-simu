## 实现与契约

`analysis-port.js` 的身份标准化继续按同一顺序递归遍历并交给 `JSON.stringify`。
将逐对象的 filter/map/fromEntries 临时数组改为循环写入无原型对象，避免额外数组和键值对分配。
Session 引用正则只在该次身份计算中建立一次；引用首次出现顺序、描述符字段过滤及物理实体编号均保留。
不缓存部分状态、不缩短键、不使用存在碰撞的摘要，也不跨节点共享可写对象。

五处证明中的回合预览统一调用正式 `advanceTurnAfterPlayerAction`，传入浅复制的根和独立深复制的 `turn`。
审计该函数及它调用的回合排序、PASS 判断和 `beginNextRound`：读取和修改均限于 `turn`，仅检查 `players` 存在。
其他根切片来自完整冻结的分析快照；若未来回合推进越界写入其他切片，须显式失败并重新审计，不能静默修改真实分支。
正式动作、Session 工作副本与 restore 的隔离复制保持原样。

`turn-preview.test.js` 比较 1104 组单席、双席、四席状态，枚举 PASS 和已完成集合，覆盖普通推进、同席、跨轮及终局。
部分复制与整局复制的返回对象和完整结果状态一致，其他根切片保持原引用并冻结。
