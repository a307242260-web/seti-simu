# 终局标记、扫描目的与固定流程执行（2026-10-28）

实验搜索 v35 的生产工厂启用 `finalMarkPlanning` 和 `scanPlanning`。两者是用户确认的策略范围调整，排除项标记 `isEquivalence:false`；未宣称与完整原生动作树同值。固定预算仍为256输入、257状态、256前沿、600ms，未放宽未完成不提交的要求。

## 终局标记

可信分析端口读取当前合法标记，使用原生 `finalScoring.markTile` 在独立的小型计分板副本上预览，再调用 `end-game-scoring.computePlayerFinalScore` 比较总分差。预览的实体序号来自独立的 meta.sequences 副本，不能改变真实序号、Session 或 RNG。除板块变体、当前槽位和公司基础收入外，已有终局计分牌的联动也计入；不只比较印刷板块公式。

评分再考虑一个明确的局部预计增量：当前数据已经足够填到计算机第四格、且有可插收入牌时，按已知收入价值固定候选，把该次收入计入标记价值。不会假定未来抽牌、对手行动或尚未获得的科技/任务。评分相同按当前价值与稳定 actionId 决定。四个落点均进行只读计分，但只执行选中的一个原生输入；后续窗口不再分四条标记路线。

这是局部选择，可能牺牲更远的收入、科技、任务增长价值。节点记录评分、假设、保留及排除动作；模型身份和前缀复用键包含该策略开关。

## 扫描目的和固定组合

扫描候选改为具名的 `scan-flow` 扇区目的。当前合法选择和已知扫描队列中的公开牌、手牌、行星、探测器、条件扫描源，复用 Science 的原生只读枚举；不能把未知补牌或跳过/结束按钮当成新的目的。标准扫描开始前也从原生扫描能力/科技来源列出已知可达目的。

同一目的内固定选择牌、扇区和次序：优先推进该扇区，读取原生下一信号槽得分、数据容量和扇区排名，比较明确的手牌/额外公共扫描标记/附加费用损失，平价按 actionId。目标暂不可选时，只按当前合法收益与成本选择固定补充步骤；可选扫描不值得继续，或附加费用已无法支付时，使用原生跳过/结束。不同扇区目的仍分别比较。

整个扫描流程复用资源计划和共享前缀执行图。遇到免费移动仍调用既有目的移动策略，不重新展开方向；真正不同的规则选择回到绑定目的的原生决定。公共补牌、盲抽等现有信息边界仍会停止。多个目的可以共用同一条原生路径，执行输入/状态只计一次，每条方案保留完整路径。

扫描原生 `scanStepChoices`、手牌选择等只读函数由 Science 导出供目录复用，没有复制一套扫描结算规则。每一步仍通过正式 input port 执行；状态、队列和 RNG 等价要求不变，预算或时间中断没有动作/证书。

实际每次机器推进仍只提交一个输入。资源/扫描宏不新增跨真实点击的内部证书；恢复依据原生未完 Session 的当前队列和合法项重建目的。真实点击后的下一次搜索可以重新规划。

## 固定执行成本

稳定、无活动 Session 且当前 fork 已加载该精确 envelope 时，下一 Action 可直接调用原生 working-copy 入口，不必先恢复同一 committed root。此优化不跳过规则校验或输入记账。

待输入 Session 仍必须恢复可写 working state；可信 checkpoint 已深度冻结时，runtime 只共享只读的 baseState/committedState，复制 workingState、队列、日志和其他控制字段。普通人类/外部恢复继续原有完整复制路径。保存仍冻结独立历史，兄弟分支、真实根、失败回滚和恢复重放保持隔离。

## 验证与限制

定向对照在同一当前源码中分别开启/关闭策略，均使用256/257/256/600ms预算：一个真实标记边界由4次输入、5状态降为1次、2状态，窗口估值均为67；单独扫描主行动由8次输入、9状态降为6次、7状态，窗口估值均为42.5。此为具体样例的相同估值，不是所有长期状态的等价证明，也不是游戏分数。

恢复优化单独关闭两项新策略，重做上一版20科技目标：两种普通缓存设置下都保留全部叶观察哈希、估值和27次原生输入，少做5次稳定边界恢复。时间为单次对照，不能将冷/热进程差异当作统一提速比例。

最终完整回归、九项Chrome、独立估值输入和来源哈希见[验证汇总](../reports/ai-foundation-20261023/fixed-decisions-final-20261028-v1.json)。八点仍为5/8；062/105/152在600ms截止时分别已执行253/232/189次原生输入，仍未完成。策略改变了后续访问顺序，不能直接用两次截止时的输入总数推算速度或棋力。没有运行完整局，没有新增终局分数或180秒验收。

现有信息/其他玩家边界、更远期标记增长、扫描中尚未公开的新牌和高级公司/外星需求目录仍属限制，不把局部通过扩展成完整游戏已验收。
