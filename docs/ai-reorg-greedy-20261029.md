# 重组弃牌的固定贪心计划（2026-10-29）

用户确认“有赚就丢，没赚不丢”，不再为同一收益判断枚举弃牌集合。搜索v40将`card_discard_any_for_income`条件选择固定为一条正边际收益执行链；正式牌效、弃牌规则、估值权重均不改。

## 决策契约

在当前原生待决队列中，比较“现在完成弃牌”和“多弃一张再完成”的已知价值。使用现有默认V的资源/手牌权重，以及Production正式终局计分预览；收入不变，未来轮初收入项在差值中抵消。失去的手牌按现有手牌权重扣除，未知抽牌仅计已知张数，不读取或抽样牌堆身份，不增加新的牌面潜力模型。

已有`pendingIncomeGain`在点击完成前尚未到账，必须放进两边的预览，先占用剩余资源容量。信用/能量、宣传/数据封顶沿原生`players.gainResources`计算；已有终局资源计分牌按正式计分计算增量。选净收益最高且严格大于零的一张，平价按actionId；没有正收益便固定点击完成。收益为零也保留手牌。

这条链在资源目的宏内直接构建完毕，不回到搜索图展开弃牌组合；原生宏的实际前缀继续进入现有计划证据，机器每次仍只提交一个真实输入。冷恢复可从当前手牌、原生未完成队列与累计待发奖励重建相同后缀，不增加另一份持久选择集合。

这是用户选定的局部贪心策略，`isEquivalence:false`。它不探索零/负边际弃牌共同形成的任务或未来牌面机会，不将减少组合声称为所有局面的同值证明。PASS强制弃牌、交易付款和其他牌内选择不套用此规则。
