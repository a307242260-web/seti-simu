# 第三轮公开奖励：留牌与第四轮终局

在同一 23 输入标准开局上，第三轮第一次分析改用阿米巴蓝 3，或对调 DLC20、DLC25 的取得顺序，都能保住 **118 盘面／164 已有资产、6 科技、永久 7 钱／4 电及一枚普通探测器**。三条分支各自延续到自然终局，固定保留 B111 时都是 **239**，固定保留 B32 时都是 **253**。这两个蓝位和两种公开取牌顺序，在原牌序的两个接续里表现等价。

把 DLC17 换成 DLC16 能留三张牌。原牌序的两种保留牌均到 **210**。在 V665 的三组换暗牌对照中，DLC16 的六个终局都低于各自同条件的 DLC17 路线。V665 保留当前公开奖励判断。

## 把移向土星的第一步固定下来

两条原牌序留牌分支都可在第三轮 PASS 前花 1 电向外一步，也可等第四轮收入后再付。每组早走、晚走的完整规则状态、会话和 RNG 在移步后相同，复用同一条自主续跑。AI 随后能再付一步并登陆土星。

| 第三轮路线 | 原自主 B111／B32 | 固定向外一步后 B111／B32 |
| --- | ---: | ---: |
| 正式第三轮 | 239／253 | **272／269** |
| 第 236 步取 DLC16 | 210／210 | 214／230 |
| 第 240 步换 DLC16 | 215／215 | 236／241 |

第 240 步保留 B32 时，固定移动把终局从 **215 提到 241**。正式第三轮做同样移动可到 **269**，仍有 28 分差距。保留探测器并延后移动可行，这批对照中原来的永久电和电脑四格对应更好的终局。

第三轮数据在白席 PASS 选牌和第四轮收入前取得。第四轮固定同一保留牌，随后由 V665 自主，其他三席只 PASS 或必选。独立复放 132 个正式动作核对原根，另复放 **31 条第三轮分支、30 条不同存档的第四轮接续，合计 3,908 个原生输入**。已提交的自主决定最多 **203 次原生输入**、最慢 **564.116 毫秒**。在 V665 源码 `9a1cafee8` 的检出目录，可运行归档里的 `node /解压目录/verify.cjs /包含V665正式记录的仓库目录` 重验。标准参照沿用已登记的续跑，策略及实验中心成绩保持 V665。
