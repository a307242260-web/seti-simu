# 第四轮：扫描顺序不是这 1,995 个节点的来源

在[化石领奖后冷根](human405-v661-r4-scan-continuation-20261110.md)用 V449 记录公共扫描的实际路径。对 60 份原生公共扫描菜单，换序复放 720 对由不同公共牌组成的合法扫描：

| 两张牌的扇区 | 原生复放对数 | 换序后差异 | 实际搜索两种顺序的对数 |
| --- | ---: | --- | ---: |
| 同一个扇区 | 96 | 忽略弃牌历史和可互换数据标记编号后相同 | 0 |
| 不同扇区 | 624 | 两个标记的绝对替换编号和最后扫描扇区；各扇区内相对顺序不变 | 0 |

两路均实际提交两次选择，剩余队列、合法菜单、资源和 RNG 对照一致。720 对中，64 对有一个顺序实际进入搜索，其余两个顺序都未走到。该计数限于这 60 份可重放菜单，不推及所有对局。真实后续价值仍可能随扫描目标变化。

隔离 V450 试验：仅第四轮已用主行动的深空探测、没有额外扇区标记时，搜索身份比较扇区内替换编号的相对顺序并保留平局，原生存档与记录仍保留原编号。化石领奖根的首选、根排序和估值不变，但 **1,995 图节点、546 次原生输入完全没降**。另外四个原生存档（第三轮 #172、第四轮开局、教师 #272、卫星压力点）的根排序、节点和输入数也未变。这个候选没有准入或合入；没有根据同分删掉实际不同的扇区目标。

## 真正重复的是扫描后各自完成一段数据收尾

该根图中有 **1,014 条资源计划边**，其中 **786 条数据、186 条扫描**。数据计划最多的是蓝槽 2（257 条）、电脑第 5 格（193 条）和蓝槽 1（156 条）。其中 **127 条**蓝槽 2 计划通往「继续蓝槽 3，再结束回合」的固定后续。每条都从同一源另保留立即结束回合的合法对照：

| 收尾比立即结束多出的估值 | 路线数 |
| ---: | ---: |
| 1 | 84 |
| 1.5 | 15 |
| 2 | 18 |
| 4.5–6.5 | 10 |

因此不应把这些数据计划按“立即结束也合法”删除。按估值差、输入数、已有移动目的和交接形状分成 8 组，各取一个原生存档，独立复放收尾和立即结束，共 **79 个原生输入**。原生状态、会话和 RNG 对照一致。两路均正常交给绿席、无待决菜单；搜索图把它记成信息边界是因为仍携带已知扫描补牌的遮蔽。短链是蓝槽选一张已知牌、再换 1 钱；长链还会插收入或先补电脑，不能用统一加分代替。最短代表实际消耗 2 池数据、增加 1 张手牌与 1 钱，盘面分不变；最长代表可多 2 盘面分、1 钱和 1 电，同时消耗池数据与一张手牌。

后续验证方向是**保留立即结束与数据收尾的真实比较，仅收拢收尾内部没有竞争的中间步骤**。需要逐个确认已知牌、固定收入、移动目的和原生交接；若中间产生新选择则回到原路径。当前没有更改生产策略、预算、正式成绩或实验中心，也没有重跑前三轮或整局。
