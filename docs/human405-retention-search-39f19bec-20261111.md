# 教学盘第三轮留存：第四轮搜索的可复用结算与反例

六个留牌／留数据的旧存档上，三种规则等价复用共省 **1,250 次原生输入**，但仍没有同时达到 **256 次／600 毫秒**。限制准备用途能更快，却会漏掉把蓝槽和永久收入用来供电的合法登陆路线。没有提交这些存档的第四轮首步，暂不改生产和正式分数。

等价复用包括普通扫描进入已知公开牌菜单、B9 已跨过补牌后的最后一次扫描，以及原生登陆的黄色痕迹。六个根完整搜索图、全部候选、首选、估值和关闭边界均相同。逐个把节省的输入送入独立正式规则内核，共核对 **426 次公开扫描前缀、512 次 B9 结算、312 次黄色痕迹**。对照完整状态和会话、合法菜单、规则 RNG 与信息屏障；搜索归一化会话编号，不将不可用的界面撤销帧计作规则差异。约千至数千个逻辑状态仍在搜索图里，减少原生调用没有消除这些准备组合。

**为何不能直接绑定移动。** 两个插收入前的存档中，正常首选先用公司换移动牌。原生复放的路线能先用蓝 2 拿电、再补电脑四号槽插一张电收入，只需一次 2 钱换 1 电就能走完登陆路线。绑定移动后立刻筹移动，换了三次电，绕掉了两个供电来源；公司换牌的原报价 203.5 被降到 202／201，两个根的首选都变成放数据，最佳报价 203。原生路径复放至显式输入结束；之后的已审计回合尾估值单独保留。两个快过线的结果因此不用于终局验证。

只绑定数据用途的试验在这六根保住了所有首层报价、203.5 最佳值和相同首选，但仍需 **820–1,481 毫秒**，深层搜索也有变化，未证实可以通用。下一步要保住蓝槽和插收入两种供电入口，再核对能否把同一登陆路线的不同准备顺序收敛到同一状态；现金兑换只能补已经证明的剩余缺口。
