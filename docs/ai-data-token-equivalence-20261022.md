# 玩家数据标记的向前等价（2026-10-22）

当前 Production 中，玩家数据标记的实体编号、显示序号和数据池展示位置不影响向前规则。
分析身份忽略这些展示事实，以及仅用于分配此类编号的 `meta.sequences.dataToken`。
实际规则状态、存档、日志和页面仍保留原值；星云数据标记不在此范围内。

计算机槽位、蓝色附加位、池数量、已放数量、溢出次数和其余字段仍参与身份。
已放标记按种类及实际目标槽位生成规范顺序；池标记只删除 id/index/slotIndex，保留其他字段。
卡牌、探测器、星云数据及其他实体编号与 sequence 没有应用此证明。

## 全部当前消费者

核对 `dataState`、`poolTokens/placedTokens`、`list*Tokens`、`data-token` 和 `sequences.dataToken` 引用：

| 来源 | 实际依赖 |
| --- | --- |
| `game/data/state.js` | 池数量决定容量与费用；计算机/蓝位集合决定可放位置与奖励。池取最左标记，但同池所有标记无不同规则属性。id只用于从同一池删除刚找到的实体；index只生成下一个显示序号及消息。 |
| 同文件的 gain / place / analyze | 获得时分配新唯一编号、递增显示序号；放置时移入相同目标位；分析时清空已放标记。操作均不按标记编号或序号给予不同奖励。 |
| `game/abilities/data.js` | 将正式可选目标与按槽位计算的奖励返回领域层；编号只存在于操作结果，未进入后续 Decision 或规则事件。 |
| `game/effects/science-session.js` | `placeData` 事件只有 owner、placementKind、目标位；收入、取牌等奖励按该目标位产生，不携带数据实体 id/index。 |
| `game/production-kernel.js` | 分析/收入/科技需求目录只读已占计算机位集合和数量；sequence 仅恢复分配器。 |
| `game/aliens/banrenma.js` | 数据支付只读池数量；不按标记身份选择费用。 |
| `game/cards/effects.js`、终局计分 | 数据任务使用公开可用量/已放量、星云信号和扇区事实；没有玩家池标记编号选择器。星云标记仍保持原身份。 |
| `game/state/high-coupling-slices.js` | 校验全局唯一合法编号、分配器覆盖已有编号；在合法唯一分配前提下重命名不改变有效性。 |
| `app/simulation-contract.js`、`app/rule-observation.js` | 观察只有数据数量、溢出次数、计算机槽位、蓝位占用与奖励；不输出玩家标记 id/index/池展示位。需求目录也不输出这些字段。 |
| `app.js`、resident renderer、训练复盘 | 原始编号与展示位置用于 UI/历史输出；不进入 `seti-analysis-observation-v1`。 |

## 一步保持与后续路径

两个合法状态仅在上述元数据不同，当前观察与正式合法 descriptor 相同。
获得数据在两边均增加一个可互换标记，或同时产生一次溢出；不同分配器继续生成各自合法的新编号。
放置均减少一个池标记、增加相同实际目标位，并授予相同奖励；取哪个池实体不改变规则结果。
分析同时清空已放集合。其他操作不读取这些元数据。
因此每个同一正式选择的后继仍满足该关系，可归纳到 owner、信息或终局边界。

池物理槽位的空洞只改变下一次取出/显示哪个等价标记；不改变可选放置目标、容量或奖励。
已放数组的历史先后不改变占位集合。剩余 Effect 队列原样保留，不删除其中任何选择或奖励。
此等价只覆盖合法向前执行；不覆盖读取 journal/展示序号的自定义效果、undo 或 Browser 原始渲染比较。
若增加按数据编号/序号/池位置选择或奖励的规则，必须重审本证明。

## 真实反例检查

`data-equivalence.test.js` 从同一 Production 根执行两组交换路径：

- 先角标取数据再放，与先放再取，产生不同池展示位置。
- 先放蓝色附加位再放计算机4号位并插同一收入牌，与相反次序，产生不同标记编号分配、显示序号与已放数组顺序。

两组均比较身份、完整分析观察、合法集和每个直接正式后继，并验证真实根与 RNG 不变。
另一组合法重命名、显示序号平移、数组重排及分配器平移，比较根与所有直接后继；
真实池数量、目标位和奖励改变的状态仍须不同。

该证明消除一类规则上无关的状态差异，不保证当前开局诊断立即提速，也不是完整局验收证据。
