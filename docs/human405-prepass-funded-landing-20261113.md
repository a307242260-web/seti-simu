# 第三轮 PASS 前为登陆定位

在标准第三轮第 258 步，白席只剩 1 电，无牌、无池数据，其他席已 PASS。原策略排除所有移动直接 PASS。新策略只在这种窄窗口检查原生移动和下一轮的公开钱电；如果移一格可使同一个有至少两枚数据的普通行星登陆，在下一次首个 PASS 公转后只差一步，且计入当前电费仍不增加总移动费，则执行固定移动。不公转时同一目标也须有足够公开钱电，总移动费也不能变贵。没有确定的唯一最优动作、移动会触发额外收益、存在在途化石或还有其他可做的动作时，沿用原策略。不读取留牌选择、未知收入牌或其他玩家的后续操作。

标准盘自主选择向外一格，位置由 (4,2) 到 (4,3)；付款 1 电。下一轮首个 PASS 后，土星登陆由两步加两电登陆费，变成一步加两电登陆费，仍有 1 电可用。四组分别交换普通暗牌、阿米巴暗牌及两者后，动作、根估值、输入次数一致。移动、冷恢复付款及下一步 PASS 都通过单点门槛，提交两个输入后完整原生存档精确一致。121 个标准历史第三轮白席根仅预定的一根变化，其余首选、估值、输入次数一致。

受控第四轮原序接续，从同一个第三轮末存档分别固定同一张留牌：不移动 253／239；向外 269／272；顺时针 253／239；向内 240／225。逆时针两组超过 600 毫秒，在该决定提交前停止。已完成接续均独立重放；这些受控分数不替代正式整局成绩。
