# 教师第三轮末段：固定数据结算通过门槛，土卫六路线仍待收敛

从教师第三轮同一起点的合法前缀出发，定位了两个独立问题。**两种外星人都已公开、仍未执行主行动时，固定放数据和插收入重复提交。复用后，同一根由 387 降到 173 次原生输入，原首选和 161.5 V 不变。** 这个根现在可以继续自主跑完第三轮。更晚，虫族 3 免费移动的策略把已经在土星的探测器移走，跳过本可当回合免费执行的登陆；保留登陆后又有连续两枚任意痕迹的预算问题。两项不能用同一处提速解释。

所有轮末均在 PASS 选牌及第四轮收入前取样。白席以外只 PASS 或做必选。已有资产分只计当时已取得的计分来源，表中的对照均不作为正式标准开局或完整终局记录。

## 数据：只复用确定结算，结果与选择没变

第三轮原生教师复盘后缀的第 26 个输入前，白席是 79 分、0 钱／0 电、6 宣传、5 池数据，手里有虫族 7、虫族 2，电脑与蓝槽空。旧完整决策的 387 次输入包括 103 次打开数据菜单、105 次选槽、46 次选收入。以前的同类复用没有覆盖两种物种均已揭示且还未做主行动的状态。

沿用放置、第四格收入菜单和货币收入的既有原生见证：两种物种在原根就已公开、其他席均已 PASS、无运输任务；可能触发其他效果、不可见收入牌、未知奖励仍按既有规则走原生。按各自节点的真实资源和菜单结算，不合并不同的电脑、槽位、钱电或牌状态。214 次复用逐条双跑：102 次开菜单、61 次无待选放置、43 次打开第 4 格收入菜单、8 次已知货币收入。完整状态与 RNG、会话（仅对齐独立会话编号）、合法动作、信息遮罩和 V 均一致。

原牌序、互换普通暗牌、互换虫族暗牌、两者同时互换的四个冷根都是 **387 → 173 次**。候选实测 **221–327 ms**，公开观察、原生菜单、首选与全部根候选值均相同。实际交回 AI 后，剩余输入全部通过门槛，自主第三轮 **98 盘面／139 已有资产、6 科技、永久钱／电 6／5**；留 2 现电、4 宣传、电脑 5 格、蓝槽 2 格和普通探测器，仍空手、无池数据和化石。教师完整原生终点是 **105／162、6 科技、永久钱／电 7／4**，另有 3 手牌、3 池数据和在运化石。这证明能跑完，不证明发展追平。

正式标准存档沿用已验证的 23 个开局输入，重放余下 236 个输入，逐一复核 211 次白席决定。首选、全部根候选值、原生次数和 3 个轮末信封均与已登记记录一致；最大 **256 次／222.775 ms**。因此标准仍是 **15／48／118**。这是固定记录的回归验证，未另开一局，未改 V41 基线或成绩。

土卫六登陆产生两枚任意痕迹。打开登陆菜单后的 2,035 次中，955 次在选痕迹、655 次在选外星人牌、416 次在接受或跳过阿米巴触发；合计 2,026 次。主要成本不在移动，也不在登陆目标本身。必须先把两次痕迹及其固定奖励按真实用途收敛，并保留新牌未知、卡牌触发及痕迹位置差异，才能让停在当前行星的改选进入生产。不能把 “免费” 当作 “所有方向等价”。

更早的受控分叉也未补齐留存：固定分析先于扫描是 93／132，AI 反序为 95／134；第三轮末两者都空手且无池数据。先固定教师第二次标准扫描而非马上往土星移动，可以到 105／148，但电／钱仍是 4／6，电脑和蓝槽被用空。标准路线则对照了阿米巴 3 移除痕迹、橙 1 取公开牌、末次分析痕迹，未有替代路线同时超过 118／164 和 7 钱／4 电。
