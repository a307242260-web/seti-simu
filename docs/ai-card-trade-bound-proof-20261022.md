# 取牌交易的信息边界估值上界与出口等价（2026-10-22）

`seti-card-trade-information-value-bound-v2` 适用于四种快速交易的待选阶段：
信用点取牌、能量取牌、宣传取牌、弃两张精选一张。
可信端口 `cardTradeBound(node)` 只返回规则依据、交易 ID 和剩余手牌数量变化；
搜索用当前冻结线性模型计算上界。默认关闭，由 `cardTradePruning: true` 显式启用。

## 成立条件

- 当前节点为本席正式 `standard_action_session_decision`，只剩该一个队列项，没有中断或快速插入。
- journal 的首个正式行动是同一 ID 的快速交易，待选 context 的 owner 与当前席位一致。
- 待选为取一张牌，或弃两张精选的纯弃牌部分；后者复用原有纯选择校验。
- 赫利昂公司；对手无保留卡，本席为空或仅有已核对的访问行星型B44；当前回合无事件奖励，没有已揭示外星人。
- 当前席位未 PASS、不在初始选择流程；手牌与公共牌仅含标准牌。
- 牌堆仍有可用牌，避免对耗尽时的无效盲抽套用成功取牌的结论。

其余队列、公司、卡牌触发器、事件奖励或外星人状态返回 null，继续正常搜索。
已扣除的钱、电、宣传均在待选节点的真实资源中，不在计算上界时再次扣除。

## 到边界的完整值

`production-composition.executeCardSelection` 在成功取得公共牌或盲抽后，
分别产生 `hidden_card_reveal/draw` 屏障；本搜索不越过该屏障继续用新牌。
弃牌点击本身没有额外效果，确认时只删除所选两张牌并进入同一取牌阶段。
在上述无额外触发条件下，没有其他资源、收入、科技、任务、分数或正式计分变化。

当前线性模型只按手牌数量估值，不读取取得牌的身份；正式计分中的类型3牌也只读保留区。
其他终局公式依赖收入、科技、任务、星云和探测事实；这些在交易待选阶段不变。
因此所有成功完成出口具有相同值：

```text
已经扣除其他费用、待取牌：剩余 handDelta = +1
尚未支付弃两张费用：     剩余 handDelta = -2 + 1 = -1
```

`evaluateHandCountDelta` 只对由 `createStateValueEvaluator` 创建的冻结函数开放。
它复制观察的手牌数组并调整数量，用相同模型重新求和；这只是数值界计算，不产生规则后继或真实收益。
直接用 `V(node) + delta × handWeight` 可能因浮点求和顺序下溢而低估上界，故不采用该算法。
终局、错误模型、错误席位及非法数量变化显式拒绝。

在此条件下该界事实上等于所有成功边界叶的值；无出口的点击循环也不可能产生更高值。
这不是普通低分准备动作的上界，不适用于弃牌换钱、电后仍可继续行动的分支。

v2的B44范围使用与主行动后证明相同的封闭模型检查，但取牌交易本身不产生访问事件，
所以不要求无探测器。B44的类型1触发状态、任务数、正式终局公式均不因取牌而变化。
这不允许移动路径跳过B44奖励；有探测器时访问木星确实能带来新的数据准备收益。
除本席这张已核对的牌之外，其他保留牌、对手保留牌及未知模型继续返回null。

## 剪枝与见证

搜索v4仅在已经真实执行得到一个比较边界叶，且其值**严格大于**该上界时，停止展开待选节点。
相等时仍保留分支，避免破坏最短输入数和 actionId 平分选择。
更换手牌权重后重新按该模型计算，不把默认权重的结论搬到其他配置。

`prunedByBound` 记录上界、严格更优叶的节点编号和值、规则证明与模型键。
被省略节点不取得竞争叶的值，也不增加虚构边。
其实际祖先如果只剩已覆盖路径，标为 `covered-by-global-pruning`，不误报成规则不可达。
逐根值标为已取得下界；全局图仍须闭合，任何未证明分支超预算仍返回 incomplete/actionId=null。
上界计算本身超过 watchdog 同样不返回动作。

当根位于纯选牌部分时，整个搜索关闭此项全局剪枝，确保跨真实点击的完成证据仍包含每个出口的精确值。
冻结函数的席位、模型版本与权重进入模型键，普通自定义函数不能伪造该能力。

## 单步取牌出口的数值等价

搜索v7新增默认关闭的 `cardChoiceEquivalence`，使用同一可信规则前提与冻结线性评价函数能力。
本项只处理 handDelta=+1、全部为正式 trade-card-selection 的多项 choose_card 阶段；
不省略 handDelta=-1 的弃牌支付集合。

证明 ID 为 `seti-card-trade-information-choice-value-equivalence-v1`：
所有选牌均经一次真实输入成功到达信息屏障，值逐位等于相同求和顺序的数量界。
因此保留 actionId 最小的一项，不改变最大值、最短输入数和 actionId 平分选择。
不同后继的牌面、牌堆、RNG、屏障种类仍不等价；只是当前模型和比较边界内的数值等价，
不能作为向前状态身份合并，也不能越过信息屏障复用。

计算发生在节点出队且未被更强的全局证明省略之后；不提前为未探索节点生成观察或数量界。
如果当前全局严格上界已能省略整条分支，不生成本地取牌执行见证。
保留项实际提交后必须为 information-barrier，且实际 V 严格等于预测值；
不符即 `SEARCH_CARD_CHOICE_WITNESS_MISMATCH`，不返回动作。

图中的 `localPlan.kind=card-choice` 记录证明、数量界来源、保留/省略动作及预测值。
省略根的 value/target 仍为 null，标记 not-executed，并引用本节点实际完成的边界叶。
图未闭合或预算不足时不返回动作；本地计算也受 watchdog 约束。
主行动后的另一类局部证明使用 `localPlan.kind=post-main`，两者分别计数。

该数值等价保持每个支付集合出口的精确值和剩余最短长度，可以在根弃牌组件内启用；
仍执行全部十个支付集合，原有全局资源/取牌上界在该组件内继续禁用。
跨真实点选复用仍核对完整依赖和全部支付集合；不把一个见证冒充其余支付已经执行。
以后若模型读取新牌身份或比较边界越过抽牌，本证明必须失效并更新版本。

## 验证与局限

`card-trade-bound.test.js` 比较全部90个真实边界叶：信用取牌3个、能量取牌3个、宣传取牌4个，
以及20种原始有序弃牌支付各4个取牌出口。默认与分数权重均逐位等于计算值，真实根/RNG不变。
真实取牌事件额外发放5信用点时，结果确实超过简单手牌界，端口拒绝该证明。
图测试覆盖严格竞争见证、平分不剪、手牌权重变大后保留赢家、错误模型/席位、预算与计算超时、
选牌完成证据禁用全局剪枝，以及被覆盖祖先的正确分类。
完整小窗口替换隐藏未来牌序后，选择、估值、输入数和取牌剪枝数保持一致。
