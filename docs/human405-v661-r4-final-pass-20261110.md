# 第四轮：完成 PASS 后，估值只保留正式计分

免电分析 08 号第四轮一分没拿，是因为搜索给已经 PASS 的白席加了无法再使用的资产价值。原对局记录里，白席一进第四轮就在 6 钱、2 电、2 张牌和 2 宣传的状态选择 PASS。原生重放到该决定，旧策略仍给 PASS **89.5 V**：已有 50 盘面分、27 终局计分，再加 10.5 资源价值和 2 手牌价值。其他三席按原记录完成，正式终局 **77 分**。

修复只看最后一轮已经写入正式 PASS 名单的玩家。此时没有白席自主行动可以再兑现库存，返回规则当前算出的总分（含终局公式已计入的资产），不再叠加通用资源、手牌或未来用途。尚在办理的 PASS 不触发这条规则；前三轮 PASS 后还有下一轮。白席已 PASS 而他家仍能行动时，对局仍是非终局。

在现行正式源码的独立快照上只应用这个修复，从相同白席决定冷开：PASS 降为 **77 V**，弃「火星轨道门户」取数据后放蓝槽换牌的路线成为首选。其后沿同一策略完成白席后续轮次，其他席保持被动，正式结果为 **59 盘面 + 32 终局 = 91 分**，比原局多 **14 分**。第四轮增分来自扫描、分析和电脑放置，另有 5 分来自终局结算。47 个白席决定的最大值是 **156 个原生输入、174 ms**；这两项峰值不在同一个决定。另一份 V440 源码快照上也得到完全相同的行动序列和终局状态，包括随机数。这个结果来自原局第四轮存档的反事实；20 局原报告仍记录 08 号实际拿到的 77 分。

同一轮末边界的原始观察、完整观察、简化估值观察和标准决定观察给出相同的 77。第三轮两处和两处运输对照的完整搜索图一致（剔除计时和模型版本），八个非 08 号冷根的首选及其估值一致。正式第四轮入口 165 个原生输入、566 ms；教师第 272 步 156 个、963 ms；卫星压力点 251 个、1,273 ms。后二者是原有超线，没用新整局掩盖。6 项 Node 回归、66 项估值输入审计、1 项正式 PASS 专项输入审计、2 项 Chrome 冒烟通过。

## 另行验证：电脑收入准备的固定流程

基于隔离的 V440 候选，V441 只尝试合并第四轮主行动后已经备齐数据、无触发且收入牌已知的连续电脑放置。路线仍到达可继续做其他事情的稳定状态；只把准备本身当成固定计划，后续蓝槽、运输和其他用途照常比较。单个决策带有限预算时保留原流程，胜出路线仍需展开见证。

教师第 272 步独立原生重放 52 条、348 个输入：全部比对了结算状态和随机数，并在搜索侧比对会话、可见范围、合法菜单和估值。725 个图节点的估值、兑现值、准备债和见证长度保持一致。原生输入仍为 166；用于保留中间步骤的搜索记录从 920 降到 636。五组交替冷测中位数 **1,187 → 1,160 ms**；七个对照图相同，卫星及正式入口没有明显改善。这版增量作为复现实验保留，未并入正式策略。
