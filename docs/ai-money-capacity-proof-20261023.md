## 为什么最多只有一次生产性钱电支出

主行动前的非取牌准备只可能是钱电兑换、两牌换资源、标准宣传/移动角标、免费放数据。
没有探测器时移动角标不能创建探测器；数据合计至多 1，不能解锁分析或计算机 4 号收入位。
这些准备不会增加信号、科技、数据总量或新的手牌身份。

| 出口 | 后续支出与边界 |
| --- | --- |
| 付费取牌准备 | 2 钱或 2 电支付一次后取牌，正式隐藏抽牌/公共补牌即停止。两牌或宣传取牌不花钱电。 |
| 扫描主行动 | 一次 1 钱 2 电。无科技或借入能力，扫描队列没有紫2/3/4追加支出；公共扫描及至少三张剩余牌保证串尾补牌的信息边界。扇区结算可能更早交给其他 owner 或产生新信息，也必须停止。其余扫描和结算不再花钱电。 |
| 研究主行动 | 花宣传；取得科技时正式 `tech_bonus_reveal` 即停止，不能继续使用新科技或公司移除能力。 |
| b23 / b48 | 至多 1 钱，正式公共补牌即信息边界；角标奖励的既有条件输入仍由规则处理。不能走过新补牌继续规划。 |
| dlc27 | 0 钱，没有己方太阳系探测器/运输化石，零电条件奖励数量为零。 |
| dlc22 | 0 钱，没有达到三信号的扇区，无法开始其扫描。 |
| b44 | 0 钱，只保留访问触发器，打出不发射；主行动后没有己方探测器，不能发生访问。 |
| 发射 | 一次 2 钱，产生普通探测器并完成主行动。 |
| PASS | 不花钱电；弃牌、收入选择及轮内推进在两侧可选相同非钱电选择。 |

后三张零效果牌与发射的主行动后不再有生产性钱电支出。此时只剩免费放数据、结束回合及
默认 V 下严格亏损的兑换、宣传角标和普通移动。没有科技蓝列奖励或新数据来源，计算机4不可达，
当前分数不会增加至金标阈值。发射之后没有B44保留牌；B44打出之后没有探测器。
因此既不会通过移动解锁数据，也不会因保留手牌多而引入新的强制收入。
普通移动每点至少花 1 个手牌/能量 V，到达最多得 0.5 宣传 V；无科技时还没有小行星额外收益。
结束回合不改变本席 V。完整费用与事件排除依据见
[主行动后路径证明](ai-post-main-plan-proof-20261022.md)。

## 构造性覆盖

取任意 B 的边界路径。在其主行动或取牌支出之前，保留全部同样的弃牌集合、宣传角标、
免费数据目标、收入与条件选择，删除钱电互换。保留的钱电收益为非负，A 的初始 2 钱 2 电
足以支付该路径唯一的生产性固定费用。删除一次钱电互换还会保留 1 个默认 V；因此钱电总值
差不缩小，且至少为 1。

若该路径在主行动/取牌的正式信息或 owner 边界结束，A 执行相同选择结束，其他估值项相同，
V 严格更高。RNG相同，金标公式不读取当前钱电；无保留任务或零资源奖励观察这项差异。

若路径进入上述无生产性支出的主行动后窗口，保留其免费放数据目标与条件输入，删除亏损
兑换、角标和移动。原路径的付费取牌可替换成实际 end_turn；费用大于取得一张手牌的 V。
无计算机4、金标、外星揭示、科技到期、跨轮或同 owner 下一回合，替换不会引入额外损失。
A 最终 V 仍严格高于 B。严格更高消除了最短输入与 actionId 平分歧义。

这不是状态相等：被覆盖节点不能复用 A 的值或生成虚拟边。搜索只记录支配节点、证明和
钱电差；富代表仍须完成真实后继搜索。任何剩余节点超预算都不能提交动作。
根为纯支付选择组件时禁用本全局剪枝，以保留每个支付出口的精确复用证据。
非默认权重、其他牌/公司/探测器、空牌堆、已有科技等情况继续原来的完整搜索。

## 身份中的分析标记

`production-kernel.prepareCounterfactualEnvelope/createCounterfactualFork` 写入
`meta.rngState.branch=true`，正式 RNG 保存只保留算法及数值状态，首次执行后该标记消失。
全仓规则没有读取此标记。`forwardIdentity` 仅剔除这一诊断字段，仍保留 RNG 算法、数值状态、
其他子流及所有实际存档内容。这使真正只差钱电的分析根与首次兑换后状态可以同组。
不是把不同随机数状态合并，也不修改 replay 或正式状态。
