# 标准第三轮：同值的两次公开蓝扫留在更短的南河三

同一标准开局，新 AI 第 138、139 步仍按 **B14 → DLC30** 的顺序使用两张公开牌，把目标从六格的天狼星 A 换成五格的南河三。两条当前回合路线均为 **111.5 V**，付款、用牌、结算与路径长度相同；新规则只改同值排序。正式前三轮仍为 **15／48／118**，第三轮 6 科技、永久 7 钱／4 电、电脑 4 格、一枚原探测器保持。换的是两枚已投入信号的位置，不改变轮末估值 **164**。

## 怎么改选

只在第三轮、外星人均未揭示或待揭示、两处同色蓝区均空、标准扫描能用同一对公开牌时比较。两区均使用公开牌列从右到左的固定顺序，避免扇区专属动作 ID 改变补牌顺序。当前回合原生图完整闭合后，只有两条路线实际提交同一两张牌、其余扫描输入相同、估值、准备债、兑现顺序与长度均相同，才保留总容量较少的扇区。没有给未来中奖、补牌或对手行为额外计分，没有增加候选、放宽单点预算或合并状态。

原牌序和替换未公开普通牌时，根决策均为 **79 次原生输入**，并在后续两个已核验的接续步骤选南河三。已有占位或缺第二次公共扫描时，不采用这条同值规则。Chrome 两项冒烟、4 项定向 Node 及 V 输入审计通过。标准旧轨迹的 89 个单独冷根首选、估值、候选值与原生次数不变；差异在第 136 步保留下来的完整扫描计划，而不是旧天狼星 A 后续冷根被强改。

## 正式前三轮与第四轮的实际兑现

标准入口唯一一次自主前三轮：**259 个输入、10.613 秒**；211 次白席决策全部闭合，最多 **256 次原生输入**，最慢 **214.842 ms**。开局后 236 个输入及三个轮末信封用 Production 独立重放。与旧标准 259 个输入相比，只有第 138、139 步的目标不同。轮末仍取 PASS 选牌和下轮收入之前。

在第三轮只改变那两次目标的受控对照里，第四轮其余由原策略自主：首两个白席回合仍为 **138／192、143／197**。第三个回合的 B9 扫描改为把两个公开信号和一次额外扫描投向南河三，补齐预埋的两枚，赢下扇区并获得阿米巴粉 2。随后的数据让 AI 把 B111 插成电收入，而非用作角标。第三个回合结束 **154／210** 对标准 **151／205**；后续真实市场和触发使两条路线继续分叉。自然终局为 **239**（172 盘面＋67 终局加分），标准登记是 **216**。这 23 分是两枚信号引起的整条后续差异，不是单次扫描的固定收益。

本版正式前三轮存档加上两个被动席必选输入后，与受控第四轮接手根逐字段一致；已复放其余 **85 个原生输入**，独立确认 239。该第四轮对照原生决策峰值 **175 次／536.954 ms**，没有另跑或另登记标准整局。V41 基线未更改。新策略仍未补齐教师第三轮的手牌、池数据、蓝槽与运输资产。

未采用的对照：把 DLC19 的两枚信号也提前压到南河三，能做到四格预埋，但失去织女一粉痕迹和早期阿米巴奖励，自主第三轮只有 87 分；分投蓝区和织女一则 95 分。调换阿米巴 0 和 DLC19 顺序能让数据触发提前，但会用掉同一笔粉痕迹触发，最终并没有多一份；完成的代表性路线为 111／157，且未保住探测器。
