# 资源目标的共享执行前缀（2026-10-28）

搜索 v34 将多条资源计划共同的原生执行步骤保存为共享图；所有目标及各自后续估值保留。普通结果缓存关闭时也不会重复执行共同前缀。全局额度仍为 256 输入、257 状态、256 前沿、600ms，没有增加预算或允许未完成搜索提交。

## 共享与分叉

只复用同一次搜索内、同一个完整不可变节点上、相同原生输入及相同规划开关的转换。该节点已绑定规则状态、Session 队列、随机状态和目标内回退控制；不按资源余额、缺口或目标名字近似合并状态，也不跨恢复复用旧节点。

各目标仍独立计算缺口、保护牌、付款集合、可达性和下一步动作。只要下一原生输入不同，就分叉；相同输入的原生结果可以共享，下一目标决定继续分别计算。close、新 root 或重设搜索策略会清空执行图。原有资源下界、贪心规则、移动时机和停止边界不变。

案例105的20个科技目标，共同执行两次宣传角标、两枚计算机数据的四次输入、一次研究入口，共7步；第8步选择具体科技/蓝槽。现在保存为7条公共边加20条目标选择边，共27条执行边、28个状态。没有删除任何科技目标，每条真实执行路径仍长8步。

共享图由 Analysis Port 保存不可变原生结果。Decision Search 的每条资源目标边保存 `sharedPath` 引用及完整 `steps`；`cost` 仍是方案实际长度，参与最短路径和平分选择。`sharedPrefixGraph` 中的节点编号是执行图编号，与 `lines[].node` 的行动选择图编号分别使用。

## 预算与证据

- `diagnostics.nativeExecutions`：本次可信端口实际执行的原生输入。
- `diagnostics.transitions`：预算计费输入。资源计划共同执行边只计一次；其他旧宏保留原有保守计费，未放宽其限制。
- `diagnostics.logicalResourceInputs`：所有已走资源方案的完整路径长度之和，包含共享步骤和中断前缀；不能称为实际重复模拟数。
- `diagnostics.sharedResourceInputHits`：资源方案中已存在执行边的复用次数。
- `graphNodes`：行动选择图中的状态。`certificateNodes` 包含共享内部状态和其他宏原有内部状态；共享内部状态只计一次，后来进入行动图时转移归属，`nodes=graphNodes+certificateNodes`。

每步复用仍检查全局时间。新增执行边和状态在执行前预留额度；未完成前缀已经发生的工作照常计费，返回空动作、空复用证书及未完成原因。输入和状态额度用尽后，完全命中已有前缀的另一目标仍可比较；它不能因此增加新的模拟或绕过时间门槛。

固定前缀的共享只用于当前搜索计算，不新增跨真实点击的内部计划证书。实际机器每次仍只提交一个原生输入，回放逐步记录，恢复重新建立搜索图。
