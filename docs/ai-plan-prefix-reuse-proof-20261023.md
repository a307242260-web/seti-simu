# 已闭合窗口的最优前缀复用（2026-10-23）

搜索v20新增默认关闭的`planReuse`；共享search-agent v2显式开启。
它只复用已经完成必要探索的同一窗口，不能使一个未闭合的首次搜索通过。
固定生产预算仍为256输入、257节点、256前沿和600毫秒。

## 可恢复的假设世界

新分析根的假设种子为`seti-turn-hypothesis-v1`，由正式公开配置的seed/gameId、席位、
roundNumber、turnNumber、actionCycleNumber和activePlayerIds确定。
同一回合的已知点击不因手牌或资源变化而重新抽取假设；恢复从当前正式状态重建同一种子，
不依赖曾经命中过缓存。规则RNG和权威隐藏世界不因分析而变化。

正式prepareRoot仍按当前已揭示事实条件分配未知物种和配置，并采样未知方舟奖励；
本功能没有删除、绕过或更改其隐私边界。不同知识、随机消费和实体状态仍进入完整身份。
若同一回合实际输入已消耗分支随机数，新的根随机状态与旧子节点不符，复用直接失效。
旧策略的counterfactual evaluate不改种子契约。

## 身份与证据

可信端口只保存本席最近一份opaque证书，最多32个已执行单输入前缀。
依赖使用已有完整forwardIdentity：资源、实体、语义数组、剩余队列、假设世界和RNG均保留；
仅沿用已有日志/临时引用、弃牌集合和数据标记等价证明。
另逐项比较完整合法信封，包含actionId、owner、authority、decisionId、family、phase、target和payload。
不能仅凭观察相同、资源摘要或下一步仍合法复用。

模型键同时绑定搜索版本、冻结V的席位与权重、调用方modelKey以及全部证明开关。
只接受state-value创建的冻结线性模型；普通自定义函数不能套用本证明。
reset、load、invalidate和dispose重建算法，不携带旧token。
关闭fork保留证书供下一真实输入；缓存容量用尽或依赖改变时重新搜索。
32项是证据缓存容量，搜索图仍按原全局预算完整处理，没有新的深度/逐根截断。

## 为何可沿用比较结论

原根图必须已闭合、存在真实边界见证，并完成值与最短距离的逆向传播。
只记录其最优路径上显式存在的节点，遇到多输入宏步便停止记录后续节点，
不把宏内部未建图的点击当作已有完整证据；其他owner、信息屏障和终局不记录后继前缀。

在最优路径的节点N，原全局最高值M仍有一条实际后缀可达。
原图完成的其他路线都不高于M；全局严格上界排除的路线低于M，
资源支配与准备归约的被省略路线也不能产生同值更短的赢家。
若N有同值更短后缀，接在原前缀后便构成原根的更短赢家，与原图传播结果矛盾。
同值同距时仍按当前正式actionId平分，因此选择、最大值与剩余最短距离保持。

根锚定的信息遮蔽可能改变牌面或requirements。当前冻结线性V只读本席公共数值、
轮次、终局标记和手牌长度；sanitizeHiddenInformationObservation保留这些字段。
所以同一规则叶在旧根和新根的遮蔽下V相同。若以后V读取牌身份、requirements或未来潜力，
必须重新审核本证明，不能自动延用。

原根行可能只有下界或未执行结论，复用时继续明确这些类别；不伪造逐分支精确值。
首次完整图以planEvidence.evidenceId登记；命中通过reusedCoverage引用原图、来源节点、
原边界见证及当前剩余距离。证书本身和完整隐藏键不导出到策略trace。

## 预算、失效与验证

建立和校验证据均计入watchdog；校验本身超时也不能返回动作或token。
未闭合搜索从不颁发证书。模型、证明开关、完整状态或合法信封改变均重新搜索，
规则异常沿用显式失败，无备用行动。

plan-prefix-reuse.test的真实复杂窗口包含10个正式输入：第一次606次模拟、后续9次各0次。
每一步均和恢复后冷算比较动作、V、最短距离及正式状态。
Session临时编号在恢复后重建；测试以一一对应的引用重命名比较完整会话，
保留引用关系、全部队列与journal，正式状态、实体ID和RNG逐字段保持。
另验证资源变化但下一步仍合法、模型/开关变化、陌生实例、信息公开、未完成和watchdog。
共享Simulation运行时也检查多输入窗口复用及恢复，纯付款组件原有续用仍独立验证。

这些是具体完整窗口和边界的验证，不是新搜索完整对局、分数或180秒验收。
