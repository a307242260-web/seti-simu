# 教学盘：终局标记 C 与在运化石的实际兑现

只换第三轮的终局标记，仍可保住标准路线的 118 盘面、6 科技、永久 7 钱／4 电。**C 没有稳定提高终局分。** 在运化石 01 也确实能从第四轮开局付清返程；固定返程比让原策略自主提高 14／6 分，但仍低于标准路线，而且新增候选尚未过单点门槛。

## 只换标记，把其它第三轮行动固定

从正式第二轮轮末开始原生复放到第三轮 PASS 前，基准完整存档与正式记录一致。分别把第 156 步原标记 A 或第 178 步原标记 B 改成 C；余下的每条正式输入仍合法，轮末状态**只差终局板块字段**，资源、手牌、位置、科技、外星人、市场及 RNG 都一致。这不同于早期「选 C 后第三轮完全自主」的 105 分、4 科技结果：少科技是后续策略分歧，不是标记 C 的规则代价。

## 化石 01：缺的是一格预算，不是没有返程

第 214 步把粉标给当时暗面的第二物种，原种子揭示虫族；沿已有的自主第三轮接续，得到 127 盘面／175 已有资产、6 科技、永久 7 钱／3 电、1 手牌和在运化石 01。该分支不是教师的化石 07，也不能把原种子的暗面用在揭示前估值。

两个第四轮同保留牌入口均有 8 钱、3 电。从化石坐标 (3,3) 到当时地球 (3,1)，规则最短的每步一电路线需走 **4 格**。固定用 2 钱换 1 电、走四格、领取同一运输任务，10 个原生输入后为 **133 盘面、6 钱／0 电／8 宣传**，未消耗主行动。交回生产策略，B111 **207 → 221**、B32 **228 → 234**，仍低于标准的 239／253。

隔离候选仅在一件公开在运化石、有 3 电且规则证明四格返程、能付一次钱换电时加入这条准备路线。没有改变其他首层报价；首选转向返程，报价分别从 202.5 到 **203.5／206.5**。计划原生复放与固定返程的完整存档一致。合并既有扫描和痕迹复用后，完整搜索图、候选、首选及估值不变，单点仍为 **240 次／624ms、287 次／718ms**。没有提交这两个超线候选，不进入生产。

新增长度各异的受控尾段均逐输入复放到完整终态，原生状态、会话和 RNG 一致；所有已提交自主决定最高 194 次／540.447 毫秒，峰值来自不同决定。没有重跑标准整局或固定二十盘。下一步更值得查的是如何在第三轮保住第 4 份永久电，同时留下可兑现的化石或任务；单换标记、只补第四轮返程都未追平标准。
