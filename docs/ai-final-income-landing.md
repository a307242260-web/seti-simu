# 末轮收入任务与已持有登陆牌

第四轮的执行计划可以使用一张当前已知的3类登陆牌。牌须只有一次免费登陆效果，没有触发或任务；计划只使用普通行星目标，即使该牌还允许登陆卫星。本路径不扩大旧的手牌未来估值范围。

先保留打牌费用，再用同一钱包支付固定移动路线。普通登陆也付得起时，只有打牌与移动的付款成本加上一张手牌的机会成本严格更低，才加入这条候选。未知牌、多个供应者和牌费不足时不使用此政策。

己方主行动结束、唯一手牌正是这张已可筹资的牌，且已就绪的收入任务由永久分数门槛触发时，延后领取匹配任务，保留手牌完成登陆。直接领取和结束回合时的自动询问使用同一条件；用牌后恢复正常领取。这是用途保护的贪心政策，不是通用状态等价证明。

移动和兑换沿既有目标计划执行，仍经过原生合法输入和统一预算。搜索身份为v487-income-landing-purpose，资源计划身份为v29，旧计划缓存失效。规则、估值权重及前三轮政策保持原有范围。

验证覆盖同根原生终局，以及普通付款更便宜、暗牌、付不起牌费、多个供应者和报价不改写原状态等反例。相关资源规划测试、唯一标准全流程、输入审计及已知困难点分别留证。整局成绩以登记实验为准。
