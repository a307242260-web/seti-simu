# Local final marks, purpose-bound scans and fixed-chain execution

Scope: (1) rank legal final marks by native marginal full final score (formula, slot and existing card synergies), including a known affordable fourth-slot income increment, and execute one local choice; (2) compare reachable scan-sector purposes, fix card/sector order within each purpose; (3) reduce trusted fork restore copying, without batching away real inputs. These are three separately measured changes.

State equivalence: retain full native state, queues, RNG and existing goal-control identity. Scan purposes use existing resource-bound control on unresolved effects; no merge by deficit or sector alone. All actual effects use native input ports. Goal/card protection is recomputed per current state. No hidden mutable purpose survives reset/restore; unfinished Session can deterministically replan from its physical queue.

Reachability: scan purposes come only from native current choices and known native scan queue sources (planet/public/hand). Resource lower bounds and existing greedy funding remain. No hypothetical hidden draw, opponent forecast, future card identity or unrestricted source enumeration. Optional card/marker consumption uses deterministic immediate reward/loss; it can stop when not worth its resource cost.

Budget: preserve 256 charged inputs/257 states/256 frontier/600ms globally. Scan flows reuse the resource macro/unique-state ledger and check each native input/context/time, including cache hits. Final-mark ranking is read-only arithmetic, not a hidden native rollout. It does not claim equivalence with exploring all long-term mark futures. Every excluded option gets policy/score/purpose evidence.

Execution: skip restoring an already-loaded committed-only boundary; next native Action still obtains its own working copy. For pending Session restores, share only deeply frozen base/committed roots inside trusted fork, clone all mutable working/control/journal state. Human and ordinary restore behavior stays unchanged. Sibling snapshots, failure/abort, RNG and action envelopes must remain exact.

Acceptance: native formula and company-income facts, all four mark alternatives scored but one expanded; named scans use fixed cards, optional skip, all reachable purposes retained, no phantom hand/probe targets; intermediates/recovery and root immutability; input/node/frontier/time failures produce no submit/certificate; restore equivalence and measurable copy/restore reduction; dated single-decision corpus before games. Final score/180s game acceptance remains separate.
