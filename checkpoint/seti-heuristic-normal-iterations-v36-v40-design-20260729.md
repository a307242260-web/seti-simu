# SETI 启发式正常迭代 v36–v40（2026-07-29）

## 固定基线与保留规则

- 固定盘面/seed：`seti-104-board-v1` / `seti-104-official-v1`。
- v35：68 / 60 / 49 / 49，均分 56.5；终局 `钱+电+手牌=12`。
- 每轮只实现一个结构候选；完整固定局均分严格上升且行为正确才保留，否则回退。
- 分数、科技、收入仍是一级评价；不增加库存分，不降低 128 node、15 代理目标或 10s 门槛。

## 五轮冻结候选

| 轮次 | 尚未闭环的结构 | 修改假设 | 否决反例 |
|---|---|---|---|
| v36 | `card:play` 只锁 family | 换牌结算后把目标收窄到新增 `cardInstanceId`，只搜索实际新解锁的牌 | 换牌后借用原本已合法旧牌收益 |
| v37 | 探测器下一步虽合法但支付低效 | 对同一锁定目标比较“直接执行下一步”和“先转换再执行”的正式资源下界，只保留不增加目标成本者 | 为花钱而放弃更便宜的正式支付 |
| v38 | 扫描到分析的跨目标连续性 | 扫描获得数据后锁定 `data:analyze`，放置与补能量保持内部路线，分析完成才计目标 | 扫描后数据不足却循环放置/PASS |
| v39 | 可转化资源仍在 PASS 前滞留 | PASS 前只允许能在正式 target requirement 中证明可兑现一级收益的目标根继续 | 用库存负分或无目标转换阻止 PASS |
| v40 | 完成目标后的下一目标选择 | endpoint/analyze/play_card 完成后释放 routeTarget，并从新 committed 资源重新选择下一目标 | 目标完成后继续追逐已经消失的 targetId |

## 公共证据

- unit：目标 identity、资源缺口、释放语义与无意义转换反例。
- fixed-board：四席分数、均分、终局资源、family 计数、最慢 Decision。
- 最终：61 unit + 唯一 full-flow、架构审计、Chrome smoke。
