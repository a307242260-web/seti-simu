# SETI 启发式均分 100 探索 v41–v45（2026-07-29）

## 阶段目标与基线

- 阶段目标：固定盘面四席均分达到 100；单轮实验仍以“均分严格上升且行为正确”为保留条件。
- 固定盘面/seed：`seti-104-board-v1` / `seti-104-official-v1`。
- v39 / Policy v16：75 / 65 / 64 / 54，均分 64.5；终局钱+电+手牌为 6。
- 当前行动结构：26 次放数据、4 次分析、0 次正常扫描、4 次打牌、14 次环绕/登陆。
- 不给动作设置固定分，不把库存计入一级价值，不通过降低 node cap 或代理深度换结果。

## 搜索义务

| 义务 | 冻结口径 | 反例 |
|---|---|---|
| 状态等价 | 继续使用 committed envelope hash、actionId、剩余深度、proxyDepth 与 routeTargetId；新增阶段必须编码在正式 targetId 或 committed observation 中 | 两个不同数据缺口被错误合并 |
| 目标可达性 | 先选定 `data:analyze` / card / probe 正式目标，再允许严格缩小该目标缺口的动作 | 先随机扫描、换资源或登陆，再从结果挑收益 |
| 数据下界 | 分析要求第一排第 6 格已有数据且支付 1 能量；已有槽位和可用数据先确定性放置，缺数据时才搜索正式数据来源 | 数据用尽后循环放置/PASS，或给分析固定分 |
| 全局预算 | 保持 128 completed-goal nodes、15 次级代理目标、`4×maxNodes` 物理执行保护、每 root 8 叶、10s 失控保护 | 把 15 误改为标准行动步数或仅收紧 node cap |
| 性能门槛 | 候选先过 unit 和单决策/短链反例；不得产生无界 successor 集，再进入完整固定局 | 未证明分支有界就直接批量跑整局 |
| 一级评价 | 只累计实际分、科技和未来轮初收入；资源成本只在一级收益相同时比较 | 给扫描/分析/打牌 family 固定分 |

## 冻结候选

| 轮次 | 结构缺口 | 修改假设 | 否决条件 |
|---|---|---|---|
| v41 | 当前轮获得任何科技都固定计 5 分 | 科技的通用资产价值只计算未来仍未开始的轮次；取得当轮的能力价值必须由后续真实行动兑现为分数、科技或收入 | 第 4 轮未使用科技仍有固定分，或真实科技收益被漏掉 |
| v42 | `data:analyze` 用尽当前数据后只能结束回合 | 保持分析目标锁定；再次轮到本席时只允许正式 `scan` 获取下一批数据，随后确定性放置并最终分析 | 恢复全动作扩展、超过 10s、扫描后没有走向分析 |
| v43 | 不同科技仍共享同一未来价值 | 蓝/橙/粉紫科技分别要求路线中有后续数据/探测器/扫描行动证据，才保留未来轮科技资产价值；即时真实收益照常累计 | 用无关动作证明科技可用，或漏掉科技即时官方收益 |
| v44 | 蓝科技附加槽奖励结算后仍被锁在 `data:analyze` | 正式选择 `blueBonus` 并结算奖励后释放数据目标，从新 committed 资源选择下一个一级目标 | 把蓝槽资源直接计分，或普通第一排放置也提前释放分析目标 |
| v45 | 分析目标缺数据时看不见扫描的真实支付缺口 | Production 投影含公司修正后的标准扫描成本；锁定 `data:analyze` 后只允许严格缩小扫描缺口的转换，支付满足后执行正式扫描 | 硬编码扫描价值、放开随机转换、扫描后没有回到放置/分析 |

## v41 预期证据

- unit：第 2 轮科技只计第 3、4 轮两个未来能力窗口；第 4 轮未产生后续一级收益的科技通用
  价值为 0；同一真实叶中科技带来的官方得分、收入仍照常累计。
- #399 反例：`blue1` 的首次科技分和蓝列数据分属于实际分；没有放入蓝色附加槽、没有继续
  转化的资源不得再叠加 5 分“本轮科技价值”。
- fixed-board：第 4 轮不得因纯科技固定分选择无用途科技；均分高于 64.5 才保留。

## v42 预期证据

- unit：分析目标在 `availableData=0`、未 ready 时只保留 `scan`；没有合法扫描时降级到
  `end_turn/PASS`；不得放开 play_card、industry 或探测器动作。
- 短链：`scan -> place_data -> end_turn -> opponents PASS -> scan -> place_data -> analyze`
  保持同一 `data:analyze` target，分析完成才释放。
- fixed-board：正常扫描数从 0 上升；分析数不下降；均分高于当前保留基线 66.25；单次决策不超过 10s。

## v45 预期证据

- projection：`dataAnalyzeRequirements` 只暴露本席数据轨缺口，以及
  `SetiScanEffects.getStandardScanCost` 返回的真实钱/电支付与当前缺口。
- unit：缺 2 电时只保留能缩小缺口的 `credits-for-energy`；支付满足后只保留正式 `scan`；
  扫描、转换、放数据本身均不获得固定一级价值。
- fixed-board：正常扫描从 0 上升并回到同一 `data:analyze` 路线；分析不低于 4；均分高于
  66.25；单次决策不超过 10s。

## 实验结果

| 轮次 | 固定局结果 | 行为与性能 | 结论 |
|---|---|---|---|
| v41 | 75 / 65 / 64 / 61，均分 66.25 | 科技 9→8 次；绿色 54→61；每候选平均 150.88ms，最慢 7.975s | 均分 +1.75；保留 |
| v42 | 73 / 63 / 55 / 52，均分 60.75 | 扫描仍为 0；放数据 26→29，转换 34→36；最慢 7.983s | 未建立扫描支付 requirement，均分 -5.5；否决并回退 |
| v43 | 78 / 63 / 56 / 52，均分 62.25 | 打牌 4→7，环绕/登陆 15→16；最慢 8.576s | 有限叶漏掉未来科技使用，均分 -4；否决并回退 |
| v44 | 75 / 61 / 53 / 52，均分 60.25 | 蓝槽奖励未形成正式后续目标；最慢 7.709s | 提前释放数据目标造成未兑现分支，均分 -6；否决并回退 |
| v45 | 65 / 60 / 60 / 43，均分 57.0 | 扫描仍为 0；分析仍为 4；每候选平均 154.20ms | requirement 只在目标锁定后生效，缺少独立目标选择节点，均分 -9.25；否决并回退 |

最终保留 v41，发布为 `seti-heuristic-policy-v17`。下一阶段应先引入不消耗行动的正式
`data:analyze` 目标选择节点，再让该目标的扫描支付 requirement 驱动转换；不能再次从
`quick_trade` 动作反推目标。
