# 分析用途报价的值与所有权

本文说明隔离候选V310的估值结果契约，未代表该候选已通过源码准入或替换正式V278。

`AmibaAnalysisCapital.quote`产生解释性用途报价，不产生Native状态、观察、Action、实体或随机信息。所有候选仍按各自的钱包、痕迹占位、公开可用牌数量、触发消费、当前终局计分及下层portfolio计算。下层portfolio是纯查询，不得原地改写传入事实。

同一次quote里，不同蓝色位置从相同来源符号布局开始，执行同一个区域的正式符号结算。区域前缀仅在确实需要时执行一次，使用中央`resolveRegionReward`及自身复制的符号账本；不单独重写符号移动或奖励规则。区域准备结果不包含钱包、痕迹占位、抽牌可支付性、卡牌消费或下层估值，这些步骤不复用。

该次quote的区域候选可以共享已结算的`researchSymbols.symbolSlots`和`symbolsById`对象。它们及各符号条目对象冻结，只读，不能用于原地继续移动。需要后续符号推演时，先调用`copyPublicSymbolState`取得自有账本。前后调用quote不共享此准备结果，不以可变输入引用作为全局缓存键。

各候选的钱包、蓝痕迹结构、区域解释结果外壳、结果数组、单条结果和move对象保持独立；正式规则的固定奖励向量沿用已有readOnlyRewards契约。来源状态、Session及RNG不由报价修改。未知牌只保留公开数量，不使用其身份。

复用范围受该次有限候选集约束，不改变候选排序、必要分支、资源可达性、原生等价身份、估值模型及预算。完整quote与旧版结果逐字段相同，是算法等价证据；是否通过256Native/600ms及自主发展验收另行验证。
