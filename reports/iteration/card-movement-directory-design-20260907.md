# 卡牌移动目的目录接入原型（2026-09-07）

2026-09-07用户最新裁决：规则上可获得访问奖励，不等于应建立独立移动目标。
下文是原型事实目录，不是当前必须全量接入的目标目录；访问注册来源schema等
实施义务随独立访问方案暂缓，不阻塞公司移动收敛。当前范围见
main-goal-movement-design-20260907.md，主要目标优先，沿途收益不默认值得绕路。

本项把此前静态目录和指定bonus路线实验向生产接入推进：从实际卡实例与当前工作
状态建立具名目的，不再要求诊断调用方手选b24/dlc12的bonus。仅实现于adhoc，
不是新生产版本，不修改4096上限，不运行AI或新的固定局。

后续接入已到当前合法首步：card-movement-guidance-design-20260907.md。单来源位置
与已注册访问共用阶段路线；联合位置随后接入多来源查询，见joint-position-route-design-20260907.md。
未注册/触发目的和生产计划链仍未接入，联合卡牌阶段也未完成行为验收。

## 输入与输出边界

`adhoc/card-movement-purpose-directory-20260907.js`：
`cardMovementPurposes(root, actorId)`消费当前工作状态，输出entries和具名excluded。
位置条件调用正式buildProbeLocationData与taskConditionMet；不另写条件判断公式。
目录只登记奖励实例及其usedKeys/claimedKeys，是否仍能推进由已有
describeEventBonusProgress/visitRoute决定；已领取记录留作事实，不代表仍可移动。

| 类别 | 来源与阶段 | 接入义务 |
|---|---|---|
| 手牌位置条件/任务 | 真实cardInstanceId+modelPath；needs-position或position-satisfied，requiresPlay=true | 到位不是获得任务奖励，仍须正式打牌与领取；联合条件不可拆成任一单艘已完成 |
| 保留区任务 | 同上，但无需再次打出；已完成任务具名排除 | 位置准备完成与正式任务领取分开 |
| 访问触发槽 | 真实实例+trigger节点；手牌requires-play，保留区awaits-event-and-choice | 被消耗槽排除；匹配与选择共用正式owner，一个事件不能把所有槽奖励相加 |
| 手牌访问bonus | 真实实例+REGISTER模型路径；requires-play | 保留完整模型路径，不把后置注册的奥陌陌5提前生效；生产注册仍需新增真实来源字段 |
| 当前已注册bonus | 本次根读取中的owner+effectId+根记录序位；registered | 不反查同模型新牌；这是根既有公开奖励来源，跨根/回合身份及隐藏分支过滤仍须按visit-source-contract实现 |
| 移动手段/修正 | b49与b124具名排除为means-not-purpose | 不制造为了获取下一次移动而移动的循环目标 |
| 对手位置条件 | 具名排除为opponent-position-not-controlled | 不能伪造成己方火箭的可控目的 |

所有卡实例必须有正式模型及实例ID；未知位置条件或未归类的移动注册效果显式
拒绝，不用none/undefined补齐来源。未实现其他目的不通过空数组伪称完整目录。

## 范围与剩余接入

本目录覆盖卡牌中位置条件、访问槽和事件bonus；**不覆盖**基础宣传、已有环绕/
登陆目录、探测器扫描位置价值、位置数据奖励、终局位置价值、虫族运输。它们仍是
完整移动设计的其他来源，本项不得独立作为全体合法方向的删除依据。

下一批生产实现还须完成：完整目录合并；手牌支付/注册时序和可达性；公司第一艘
按主目的、第二艘按其他有效目的的阶段路线；沿途不同收益的保留；目标/origin/
真实planStep传递；来源、工作进度及公司额度的计划依赖；隐藏信息和保存恢复。
本项不改先移动、再数据合并、再剩余截断热点的顺序，也不登记为性能验收通过。

## 实证

`card-movement-directory-20260907.json`由同名verify脚本生成，保留四份既有输入
SHA256。242个正式模型递归得到8位置条件、16访问槽、11收益bonus、2移动手段。
这是静态模型覆盖，不外推到全部非卡牌移动目的。

真实42及已保存后段各读出一个dlc11位置任务，明确仍需打牌和正式任务领取；
148/497打牌前各一个待注册访问目的。只重放这两个既有正式路线的10个输入，
每步Action与既有证据一致且提交成功；注册后每步恰好一个注册目的，没有离手牌
重复待注册。497首站土星的usedKeys=[saturn]且claimedKeys为空，终点才有领取。
共14次工作状态读取保持完整状态/RNG/序号不变；每项身份唯一、来源和阶段存在。

没有重跑全盘。生产基线仍96e60c14：135649节点、36截断、均109.5；本原型不改变
这些数字。已检查README、AGENTS、AI/RL接口、规则与存档说明，未改生产接口或
规则，无需把原型写成已实现能力；仅同步性能计划与移动设计状态。
