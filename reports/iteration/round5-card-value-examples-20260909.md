# 第五轮：确定成本算例与扫描口径敏感性

2026-09-09，设计验证，不是生产模型或搜索改动。原始输出见同名JSON，
脚本adhoc/check-round5-card-value-examples-20260909.js，只处理明确列出的7张牌；
遇到范围外效果显式拒绝，不默认0、不把部分算例冒充182张牌覆盖。

## 成本来源与不重复计入的边界

- 普通牌成本来自cards/effects.getCardPlayCost，另扣本牌平均价值6且只扣一次。
- 标准发射基础成本来自abilities/rocket.DEFAULT_LAUNCH_COST=2钱，名义价值20。
- 标准扫描基础成本来自abilities/scan.SCAN_COST=1钱2电，名义价值26。
- 完整扫描行动按26折算后，不再把该行动内的正常扫描/奖励重复加分；卡上另外写明的
  额外扫描单独计算。例如b9是26加一枚额外扫描，不是26再加整个标准扫描的全部效果。
- 这些算例限定第一轮名义单位、无公司/科技减免。生产实现仍需通过getLaunchCost/
  getStandardScanCost和实际目标费用统一减免，不能把本表20/26硬编码为所有玩家的实际成本。
- 《拨款》使用明确公开的b3、b16、b69三牌算例，最佳角标为1数据=6，获得牌按均值6。
  净值6+6−10−6=−4。它与旧“全目录平均角标4.8242”算例不同，不能混称同一输入。

## 两种扫描解释必须区分

用户原话“卡牌上的扫描标记略大于1数据，7”存在下面两种实现解释。已异步确认，未获回复；
不改变正式规则，不把默认推荐项当用户已提交。

| 算例净值 | 7包含随扫描取得的数据 | 信号本身7，数据另计6 |
|---|---:|---:|
| 高级导航系统 | −6.5 | −6.5 |
| 阿尔冈金射电天文台：4次无数据扫描 | −12 | +12 |
| 阿番西博天文台：完整扫描+额外扫描 | −3 | +3 |
| 突破聆听：1移动+带数据扫描 | −4 | +2 |
| 拨款：本表公开牌算例 | −4 | −4 |
| 低成本航天发射 | +4 | +4 |
| NASA创新先进概念计划 | −5 | −5 |

第一列将信号拆为1、随扫描数据6；第二列将带数据扫描整体计13。
明确gainData=false时不增加数据6，repeat乘整次收益。标准完整扫描的替代价值26
保持不变，不能随这两种解释把基础行动内部效果又加一遍。
净值是打牌模型收益，不是持牌总价值；负净值不代表卡牌没有弃牌角标/收入等用途。

## 远期成本算例

高级导航系统的3个触发槽分别给1电、1数据、1移动：基础奖励8+6+5=19，预期半值9.5；
资源1钱和本牌合计16，不折半，净值−6.5。本例只对3个正式一次性槽各计算一次，
不把任意可重复事件都假设成3次。

NASA创新先进概念计划不只有即时盲抽3牌，还包含“空手牌后精选1牌”的任务。
即时18、任务预期3、资源成本20、本牌6，净值−5。首版算例断言“无任务”失败，
发现遗漏后读取完整模型补入任务，才生成当前检查点；未修改生产，也没有吞掉该遗漏。
