# 第五轮新 base 合并与策略分档（2026-09-09）

## 结论

第五轮的主目标是：在固定预算内让搜索更完整，优先删除不可能完成、没有收益或
仅由非语义状态差异产生的搜索。历史分数下降不作为恢复错误行为的理由。

本次从 `trigger-scan-mapping-20260907` 起重新建立 base：

1. 正式规则、公开信息边界、状态恢复、错误传播和事实估值修复进入正确性层；
2. 能证明不删除有效方案的计划依赖与支配剪枝进入搜索语义层；
3. 牌序、牌面价值、动作偏好等策略只归档，不进入 base；
4. 方舟、符文族及尚未完成整套验收的会话身份问题只记录，不扩大本轮实现。

新 base 不是“历史分数最高版本”，而是后续剪枝与策略比较的共同正确前提。

## 策略档的复用契约

策略记录不是“无价值迭代”。每项须保留：

- 当时优化的决策与观察到的局部收益；
- 依赖的规则版本、搜索预算、候选生成范围和价值模型；
- 已知反例或完整局退化；
- 重验触发条件：正确性 base、状态等价、剪枝、卡牌价值或预算任一变化。

其中外星拿牌贪心只能比较同一次公开选择中的多张明牌；盲抽没有牌面，不能参与
牌效比较。赫利昂“优先取得可牺牲科技”是公司策略：需综合 6 宣传、科技背面奖励、
收入机会和公司刷新价值；它不改变“失效科技未来能力为0”的事实层结论。

## 暂不纳入的正确性问题

`session-identity-isolation` 已证明同快照在同实例恢复后可能因运行计数得到不同会话身份，
但候选尚缺跨版本/不同动作、真实 Chrome、冷搜索和唯一完整局验收。本次只保留设计与
复现证据；后续以独立正确性修复处理，不和第五轮剪枝或策略调权混合。
