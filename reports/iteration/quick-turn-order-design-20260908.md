## 根因与选定方向

expected-score-evaluator的无绑定目标后继同时输出targeted和controls。环绕奖励完成后既输出当前可填的数据目标，也输出end_turn；结束回合后selectSecondaryAgentRouteTarget又自动绑定数据目标，所以再次填数。rule-composition的exactNodeKey保留完整状态和动作身份，两侧mainActionCompleted及回合计数不同，不会提前合并。不同routePlanId又是独立来源义务，不能直接删掉。

方向：仅对结束回合的后继调度实行“已经在同来源排队的快速行动先做”顺序规则，保留正式合法集、完整状态键和全部主要目标。不是把所有快速行动塞在结束回合前执行，也不是删除end_turn；end_turn后仍可选择下一次主行动。

## 实现前必须闭合的矩阵

| 边界 | 要求与禁止项 |
|---|---|
| 唯一owner | rule-composition负责搜索来源与队列，expected-score-evaluator负责目标准入；正式执行器不改 |
| 对应前序确实存在 | 只能对同一来源已生成的快速行动做归一，不能只看正式legal集。某动作虽然合法，前序目标目录可能没有列出；直接删后序会丢准备路线 |
| 状态等价 | 只忽略上述已核验的回合记账字段，并核对完整其他状态；任务到期、回合奖励、公司额度或资源变化不能被摘要相同吞掉 |
| 新动作介入 | 新回合主行动、新可用快速行动或奖励改变依赖时，重新判断，不把旧禁用集合永久带入后续目标 |
| 条件闭包 | end_turn可能先进入里程碑等奖励Decision及pendingFocalAdvance；必须覆盖等待输入、自动排空、恢复后推进三条路径，不能在条件链未结算时归一 |
| 来源与共享物理节点 | 顺序约束属于origin，不写committedState；originKey需区分不同顺序义务，不能让一条来源的约束污染其他来源 |
| 代表分支与预算 | 前序代表仍需真实排队；若前沿裁剪将其删去，应如实记录预算不完整，不能宣称后序删除使搜索已完整 |
| RNG与隐藏信息 | 不改branchKey、RNG种子、实体序号和hidden barrier；未知牌身份不参与偏好；随机奖励采样变化不得误标为完整确定性等价 |
| 统计 | 单点记录顺序归一的具体行为、对应代表和节点差异；完整局需保存执行预算与前沿预算字段，缺失字段不作0 |
| 验收 | 当前21对入口是否消除、其他真实主目标是否仍可达、失败0；单点性能通过才跑新版本全盘，分数下降先归因 |
