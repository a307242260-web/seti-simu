# 路线等额奖励不重搜：冻结设计

2026-09-08，基于 069ce288（生产奥陌陌修复 5a61fe32）。目标是消除第 356 步因金星
已有登陆数 2→3 而发生的 4096 重搜，并覆盖同类环绕/登陆/卫星目标，不硬编码金星。

## 状态等价与职责

这里比较的是已有计划所依赖的事实，不合并规则状态，也不宣称两个完整局面等价。

| 语义 | 唯一来源 / owner | 保存与比较 | 边界与证据 |
| --- | --- | --- | --- |
| 终点奖励 | production-kernel 已有 planetRewards 正式构建结果 | candidate.endpointFacts.rewards，完整效果而非分数摘要 | 环绕首次/后续；普通登陆首次、火星第二次、奥陌陌前三次；卫星固定奖励 |
| 终点成本 | 同一候选 choice.cost（正式 abilities） | endpointFacts.cost；路线另存 required credits/energy | 环绕折扣、科技折扣、移动支付变化仍失效；资源余额不作为成本 |
| 自己标记与后续操作 | 正式 planets 或 aliens.aomomo 面板数组 | 终点己方 orbit/land/satellite 标记及其数组位置 | 他人尾部追加且奖励不变可复用；自己的数量/位置/身份变更必须失效 |
| 卫星占用 | 正式 listLandRequirementsAt 决定候选存在性 | 绑定具体 targetId 与 sourceId | 目标被占候选消失则 miss；无关卫星变化不按总数失效 |
| 标记移除 | play-domain REMOVE_PLANET_MARKER 的 planetId/kind/index | 同目标段具名 planet-marker 依赖，事实取各步之前 | 当前合法性仍重验；前置准备同样检查该位置，不能拿未来事实回填 |
| 移动与来源 | 既有正式路线目录 | 保留 requirement/source/rocket/首步/步数/付费点；增加总资源成本 | 公司额度、第二艘独立目标、路线变化与收入路线原样检查 |
| 目标完成与奖励 | 既有 compilePlanSteps 分段 | 不改变深度/目标/完成阶段切断和 source 子段 | 完成后释放旧路线，仍检查奖励选择 |
| 版本与恢复 | 计划唯一 owner plan-continuation | plan v3；probe requirements v3 | 旧计划显式拒绝；reset/load 仍清空，不迁移持久状态 |

候选 endpointFacts 在已有结构缓存构建处计算，缓存键已经包括 planets、aliens 和
player.techState，包含本次所有来源；不加缓存、不加环境分支。奥陌陌读取自身面板，
不假设普通 planet record 有该物种。所有读操作只提取公开标记、正式效果和成本，
不读牌堆顺序，不新增 RNG/id/sequence 消费，不修改正式规则或 Decision owner。
卡牌 forceFirstLandingReward 仍按正式卡牌执行：通用路线事实保持标准奖励，可能
保守重搜，但不误放行；没有把未知卡牌效果当成标准奖励等价。

移除索引依赖按同段具体选择生成；当前公共观察的普通行星标记已含 owner/color，
只需保存本席可移除标记的 planet/kind/index 与内容，不暴露隐藏信息。
代码审查发现 DLC39 allOrbitOrLand 正式实现只计本席标记，不是全体玩家标记总数；
仍保留自身标记事实，不能仅以奖励相同跳过它。

## 删除账与范围

生产 capturePlanStep.routes 删除原始 markers 比较，改为 endpointFacts + requiredCost；
scopedFact 不允许缺失的新事实。旧 endpointMarkerCount 只留给明确标注的历史诊断，
不作为生产复用入口。规则合法集、搜索根/后继、排序、评价权重与预算不变。
既有 AoMoMo 多目标选择摘要使用普通行星计数的可疑调用另行记录，不混入本性能项。

## 验证门禁

1. unit 反例：等额追加 hit；奖励/费用/自己的标记/目标卫星/来源/移除索引改变 miss；
   同回合、奖励阶段、第二艘、缺失事实和旧计划拒绝；输入不变。
2. 正式路线目录证据：16 类环绕/登陆目标与卫星的 endpointFacts 来自正式效果，
   奥陌陌次数不依赖普通星球记录；实际奖励队列仍由已验证共享内核执行。
3. 真实 306 单根不超过 30 秒，记录实际耗时/物理节点/输入/选中链；完整录入新计划，
   正式重放至 356 后检验 hit，并真正执行剩余合法链，不能只修改诊断观察制造命中。
4. 固定全盘按去重流程一次验收，均分至少 108.5 且不得以涨分替代实现正确性；降分先归因。
   本项若仅单点通过，不宣称整局通过。记录全部战略/控制截断及实际失败。

全局 node=4096、time=30 秒及现有深度/beam 设置不变；本项通过减少整次无必要重搜
降低物理工作量，不截掉搜索树、不改记账。没有修改可达性或资源下界剪枝；成本来自
原生需求目录。单决策门槛通过前不跑全盘。

## 实施与阶段证据

已按设计实现：路线目录提供 endpointFacts，计划 v3 使用实际奖励、成本、己方标记
与具名移除位置；普通原始计数退出生产复用检查。未改根/后继选择、权重、预算或正式规则。

- `plan-continuation`、`machine-player-coordinator` 两项 unit 与唯一 full-flow 通过；
  全部正式环绕/主星奖励表按已有数量 0—4 比较等额/非等额，其他成本/来源/自身标记/
  旧版本/缺失/移除索引反例通过。语法、diff 与 V 输入装配审计通过。
- `route-reward-356-verification-20260908.json`：正式重放至 306，在新实现运行唯一根
  搜索，15.418675 秒；战略 4096 节点/4981 输入，控制 1/1，实际失败 0，主行动相同。
  后续棕方通过真实协调器复用（其余席位复用旧记录 Action），356 用 69.088ms 实际
  提交登陆，搜索次数为 0；357/358 奖励和结束回合继续 hit，至 359 的 Action/after
  与旧局一致。不是修改观察副本制造命中。
- 旧 356：战略 4096 节点/5351 输入/11786.300ms，控制 1/1/11.482ms；新实际主链
  输入仍逐项提交，不减记账。本点消除 4096 战略节点，但尚不证明整局收益。
- 306 新根比前版孤立测量 13.673 秒慢约 1.75 秒。新事实增加复制和比较工作量，
  暂未归因其中成本与运行波动，不能把单点复用收益直接外推整局提速；全盘必须实测。
- `route-endpoint-facts-verification-v2-20260908.json`：6 个正式恢复/奖励场景，
  共覆盖 24 个实际目录目标（7 环绕、8 主星登陆、9 卫星）。奖励和成本逐项与正式函数
  核对；奥陌陌首牌及前 3 次数据实际到账。木星环绕因既有 scoreGain<=0 门控不生成
  路线，本项不新增目标；其奖励等价分段在 unit 的正式奖励表遍历覆盖。
- 初次卫星夹具只填玩家科技而未同步供应，被恢复门禁拒绝；已改为通过正式
  takeSelectedTechTile 取得科技，保留旧失败记录，没有修改生产校验或绕过状态守恒。
