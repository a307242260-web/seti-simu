# 第五轮牌值：手牌与已打出牌的收益归属

2026-09-09，基于1a069f6c，只读审计和设计验算，尚未修改生产估值器。
检查点round5-card-lifecycle-20260909.json覆盖182牌：90张打出后留桌面，其中
触发牌27、任务牌45、终局牌17、冥王星持续能力1。

## 纠正此前设计中的错误理解

`reservedCards`是已经打出的牌，不是等待花行动取回的预留手牌。
正式play-domain PLAY先扣资源、移出手牌，类型1/2/3或reserveAfterPlay才进入该数组。
只有明确的RETURN_UNFINISHED_TASK_TO_HAND等效果会把牌放回手牌；不存在通用取回操作。
PASS保留堆精选是另一套牌区，不能根据reserve字样合并语义。

因此此前“保留牌取回义务另算”应删除。第五轮不能把H应用于整个reservedCards，
也不能将旧V的打出效果×0.25替换成完整打出效果。两者都会重新估算已兑现收益。

## 唯一计入位置

| 牌的位置/状态 | 估值内容 | 不得再次计入 |
|---|---|---|
| 可见手牌 | H=max(即时+半值远期−打牌资源成本,角标) | 不另加普通牌均值6 |
| 未知手牌 | 普通均值6/外星均值12 | 隐藏cardId对应效果或角标 |
| 已打出触发牌 | 未在consumedTriggerIds中的槽位奖励×0.5 | 已消耗槽位、打出费用、角标 |
| 已打出任务牌 | 未在completedTaskIds中的任务奖励×0.5 | 已完成任务、已兑现playEffects、打出费用 |
| 已打出终局牌 | 已经由正式scoring→securedEndGameBonus计入 | 不再给cardValue加半份或全份牌分 |
| 已打出冥王星能力牌 | 独立解锁能力义务，非可再打手牌 | 不预发环绕/登陆奖励、不计角标 |
| 正式终局 | 只用officialTerminalScore | 所有未兑现的牌值预期 |

手牌中的终局预期仍按用户0.5口径计入；正式打出后已有计分投影是唯一来源，
此设计不改规则计分，也不把已获得分数折半。数量基数使用公开上下文的具体设计仍待闭合。

读取剩余槽位必须纯读cardEffectState，不调用会补写状态的ensureCardEffectState、
collectMatchingTriggers或collectReadyTasks。无消费状态时按尚未领取处理；正式状态归规则，
估值不另存消费列表，不修改RNG/ID或Effect队列。
