04 / DECISION ORDER

一次决策按什么顺序做

1
初始设置特例
不跑反事实。固定四席优先复刻已登记高分开局；非固定席位按正式初始效果与统一资源价值评分。插收入按该牌的 income code 选择未来价值最高的收入轨。
2
终局标记特例
当合法集全是 a/b/c/d 终局板块时，直接用正式板块公式计算 baseValue × 下一空槽倍率，选即时终局分最高项。
3
标准策略选择
生成每个准入根动作的真实 outcome；只有 status=settled、存在合法叶且 selectable=true 的候选进入池。
4
稳定排序
每根先选真实叶：主价值相同时优先少丢数据，再按可选 V、总价值、真实得分、少交易、浅目标和少提交选叶；根动作继续按既有策略稳定排序。
5
受控兜底
优先已结算的条件/控制动作；没有选择空间时允许唯一合法动作。除此之外选不出动作会抛错，不回退到任意业务动作。

战略搜索

  • 根候选：只取目标目录绑定动作。
  • 根动作优先执行；虽然传入 maxLeaves=8，战略搜索不启用叶数截断。
  • 共享全局精确最小堆 frontier；先为每个仍存活根保留一个最优节点，再填满 256。
  • 未绑定后继最多展开 3 层；深度/beam/node/time 截断都显式记不完整。

结束与退出的评估

  • 未做主行动时，以 pass 退出本轮；已做主行动时，以 end_turn 结束回合。
  • 两者在各自合法阶段接受短模拟评估：最大深度 1、每根 1 叶，节点预算等于控制动作数。
  • 模拟在 PASS 决策边界停止，不执行对手回合。

QUICK-TIMING-01 已生效：主行动前围绕目标准备资源和容量；主行动后仅保留推迟可能损失的移动、指定公共牌获取及必要准备。移动用一次正式转动对照证明距离风险，不假定对手必然转动；普通移动和实际移动角标共用窗口，正式条件奖励不被拦截。

待迭代 · ROUND-PLAN-01：尽量提前规划整轮内的多个主行动与资源安排；end_turn 后继续考虑自己下一次行动，PASS 才结束自己的本轮行动规划。执行中根据局势变化调整剩余计划。此为迭代方向，尚未实现。

树内未绑定动作

触限记录（2026-09-11 补充）：后续运行逐次记录叶数、256 队列节点、4096 执行节点限制的启用状态、实际上限、触顶与截断，并进入日志和复盘报告。战略 8 叶限制标为“未启用”；旧运行缺少的统计标为“未记录”，不视作零次。

待迭代 · GOAL-ONLY-01：没有目标可以不尝试，不必按固定动作优先级展开普通未绑定后继；目标完成后可先寻找下一目标。必需结算与合法的结束/退出流程保留。此为迭代方向，尚未实现。

目标完成后或未绑定阶段允许继续形成新目标。普通未绑定后继按 family 基础顺序加净资源收益排序：orbit/land 9、launch 8、research 7、move/scan/analyze/place_data 6、play_card 5、industry 3、quick_trade 2、card_corner/complete_task 1。但 move、quick_trade、card_corner 实际从未绑定后继排除，只能经目标绑定进入。

完整性不是穷举。 max depth、未绑定深度、beam 与节点预算都是显式有损边界；已有真实叶即使遭裁剪仍可保持 settled，但 searchCompleteness 必须标 incomplete。没有叶时为 unresolved，frontier 不能冒充收益。

隐藏信息与失败

信息屏障

随机补牌、盲抽、外星揭示后，未知身份继续保持 opaque。可以用数量做通用支付，不能用未知牌面规划打牌、卡角或定向能力。

随机分支

分支 RNG 从 root identity + actionId 派生，保证复现；消费随机后 outcome 标 low confidence，不代表 Policy 可预知未来。

失败语义

规则执行异常、目标选择异常、缺叶、过期动作、非法 owner 都显式失败。fork 清理也失败时保留聚合错误。

07 / VALUE MODEL

叶到底值多少

Primary(leaf) = Δ(已兑现分 + 已锁定终局分) + Δ科技未来效用 + 新增收入的未来发放价值 + Δ外星人牌价值 + Δ宣传研究机会

这是对真实执行后叶状态的评价，不是动作标签分。一个 launch、move 或 play_card 本身没有固定奖励；只有当整条真实行动链兑现分数、能力、收入或目标进度时才有价值。

08 / PLAN CONTINUATION

什么时候复用上次搜索出的路线

TURN-BOUNDARY-01：正式多席与可信反事实均验证，新 turn 未完成主行动时旧 end_turn 不合法，先由合法性拒绝。PASS 独立比较退出时本席资源、手牌、轮次及可见机会；条件未变可跨 turn 复用，变化或缺证据则重搜。

winning leaf 若含至少两步真实输入，会编译成 seti-action-plan-v4。协调器只保存尚未执行的后续步骤；每次提交前重新检查，而不是盲放整条宏指令。

命中必须全部成立

  • 下一 actionId 仍合法，actor 和动作语义未变
  • 计划步骤证据完整且版本为 v4
  • 外星揭示数量没有增加
  • 当前步骤依赖事实与记录一致
  • 自由决策的后续具名事实存在性/内容一致
  • 快速行动仍满足当前时机；指定牌身份、公司额度及准备资源依赖一致

会触发重搜

  • 路线奖励、费用、己方标记、来源或移动阶段变化
  • 目标科技、扇区、外星痕迹、公牌、数据布局、终局板块变化
  • 后续计划依赖提前发生变化
  • PASS 的退出资源或机会变化，不比较无关对手资源及回合计数
  • 缺证据、schema 不匹配、动作失效或观察不完整
它不是“状态完全相等才复用”。 对手资源变化、无关扇区变化、无探测器移动的旋转等不影响具名目标事实时可以复用；相关事实变化则立即 miss。计划只驻留协调器，reset/load 会清空，不写入存档。

已揭示且首痕迹已存在的同色额外位，按稳定ID保留一项；方舟槽、解锁、正面奖励不纳入，有未完成普通任务或已打外星牌时不作此筛选。标记归属仍不同，可能影响未来牌的槽位条件，因此是局部贪心，不是等价去重。

主行动前同一探测目标的普通移动，从合法最低成本首步中优先选择目录nextStep；不可用则取目录中的合法替代。不同目标独立选择；免费条件移动与主行动后窗口不减少。沿途奖励可能不同，因此是有损贪心，不是状态等价去重。

永久收入目标只接纳正式增加收入轨的收入选择或本牌插收入；重组按收入角兑现的是一次性资源，不属于永久收入路线。其合法打牌与奖励规则未改。
